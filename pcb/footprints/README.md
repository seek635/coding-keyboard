# Footprints

- `SW_Kailh_Choc_V2_1.00u.kicad_mod` — from [kiswitch/kiswitch](https://github.com/kiswitch/kiswitch) (switch footprint library). See the upstream repository for its license.
- `XIAO-nRF52840-THT-ClaudePad.kicad_mod` — derived from Seeed Studio's official `XIAO-nRF52840-DIP.kicad_mod` (14 × 2.54mm through-hole pads), rotated so USB-C faces -Y; PCB drills enlarged to 1.0mm for standard 2.54mm headers. See the upstream Seeed library for its license.
- `XIAO-nRF52840-SMD-ClaudePad.kicad_mod` — retained for reference only (the board now uses the THT footprint); derived from the Seeed Studio XIAO Series Library.
- `D_1N4148_DO35.kicad_mod`, `JST_PH_2.00mm_THT.kicad_mod`, `BAT_WIRE_PADS.kicad_mod` — project-specific footprints drawn for this board.
