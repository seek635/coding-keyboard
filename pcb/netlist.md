## 2. 二极管方向

`diode-direction = "col2row"`

**阳极接列线，阴极接行线（电流 列 → 行）**

即每个按键回路：**列线 → 二极管阳极 → 二极管阴极 → 轴体 → 行线**

> 接反不会烧，但矩阵读不出来。修正二选一：所有二极管掉头，或把固件 `diode-direction` 改成 `"row2col"`。

### 大键并联接法（重要）

**ENTER**（2u）—— 定位板开 2 个轴孔，**2 个轴体电气并联**到同一个矩阵交点 （ROW2 × COL4）：

```
  轴体① 引脚 → COL4 ｜ 轴体① 另一脚 → 二极管 → ROW2
  轴体② 引脚 → 与轴体① 同一条线（并联）
```

**SPACE**（4u）—— 定位板开 3 个轴孔，**3 个轴体电气并联**到同一个矩阵交点 （ROW3 × COL1）：

```
  轴体① 引脚 → COL1 ｜ 轴体① 另一脚 → 二极管 → ROW3
  轴体② 引脚 → 与轴体① 同一条线（并联）
  轴体③ 引脚 → 与轴体① 同一条线（并联）
```

> PCB：这几个轴体的焊盘用铜箔连到同一条行/列线。
> 手焊洞洞板：用一根导线把它们的引脚串起来。

## 4. Choc V1 轴体 PCB 封装

原点 = 轴芯中心。坐标已交叉验证两个独立开源封装库（daprice / siderakb），完全一致。

| 特征 | 坐标 (x, y) mm | 孔径 mm | 类型 |
|---|---|---|---|
| 电气引脚 1 | (0.0, 5.9) | 1.27 | 金属化 |
| 电气引脚 2 | (-5.0, 3.8) | 1.27 | 金属化 |
| 轴芯中心孔 | (0, 0) | 3.429 | 非金属化 |
| 侧固定孔 ×2 | (±5.5, 0) | 1.7018 | 非金属化 |

> 两电气引脚间距 = √(5² + 2.1²) = **5.42 mm**
