〇、真实 3D 渲染（KiCad 引擎，由 tools/gen_step_models.py + tools/attach_3d_models.py 生成）

正面（焊接面朝上）：14 个轴体座 + 12 只二极管（官方模型，色环红端朝左）+ 右侧两排金色排针脚。

背面（从板底往上看，左右镜像）：右侧主控 NoLogo NRF52840（黑色 NRF 屏蔽罩、金色 B+/B− 焊盘、银色 USB-C 朝右壁）+ 左侧电池（红线头朝主控方向）+ 黑色排针胶条夹在板与主控之间。

〇·二、焊接进度图（每一步焊完长这样）

由 tools/render_steps.py 从打样板文件逐件挂模型渲染。另有一份与外壳同体系的 OpenSCAD 参数化模型 cad/pcb_assembly.scad——用 OpenSCAD 打开后改 STEP = 0..5 可任意旋转查看每个步骤，改 VIEW="in_case" 可看装进外壳的效果。

第 0 步 · 裸板——到货验收：对着俯视图核对丝印位号 D1~D12 / JP1 / JP2 / PWR / LEV。

① 二极管 ×12——卧式贴板，色环端（红）一律朝左。

② 排针 ×24 + 主控——胶条剪掉，金针从正面伸出；主控元件面朝下焊在背面（下图），USB 朝右壁。

③ 飞线——电源开关（板左缘）、复位按钮（板中部黑方块）、电池（背面银白大板，红线头朝主控）。此时从轴孔能看见电池。

④ 轴体 ×14——全部卡进定位板后整体压下再焊，STOP 与 ENTER 第二轴的定位脚悬空属正常。

⑤ 拨杆 → 完成——拨杆本体装外壳右壁（图中缺口处示意），两根引线焊 LEV1/LEV2。
