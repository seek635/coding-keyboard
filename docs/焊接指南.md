# ClaudePad 焊接指南

> 板子已到货并验收通过后，按本文档焊接。焊接对照数据来自 `pcb/netlist.md`（自动生成，勿手改）。

## 0. 焊前准备

**工具**：电烙铁（350℃±10℃，细尖头）、焊锡 0.6mm、助焊剂、镊子、斜口钳、万用表（通断档）

**元件清点**（对应 `docs/新手采购清单.md`）：

| 元件 | 数量 | 焊在哪 |
|---|---|---|
| 1N4148 二极管（DO-35 玻璃管） | 12 | 正面，卧式 |
| 主控 NoLogo ProMicro NRF52840 | 1 | 背面（直焊排针） |
| 排针 2.54mm（1×12）×2 或剪配 | 24 针 | 正面孔位 |
| SPDT 拨动开关 | 1 | 外壳右壁（引线焊 PCB） |
| 电源开关 / 复位按钮 | 各 1 | 飞线焊盘 |
| 轴体 Choc V2 红轴 | 14 | 正面 |
| 电池（带线） | 1 | 飞线到主控 B+/B− |

**极性铁律**：二极管玻璃管**有色环的一端 = 阴极（K）= 接 ROW 线**，无环端 = 阳极（A）= 接 COL 线。12 只必须同一方向，插反不烧但按键读不出来。

## 1. 焊接顺序（由矮到高）

> ## ⚠️ 2026-10-11 两个必须知道的改动
>
> **① 顺序改了：先焊轴体，最后装主控。**
>
> 原顺序是「② 排针+主控 → ④ 轴体」，但**回车第2轴、语音这两个轴体的 4 个电气脚
> 正好在主控正下方**。主控一旦装上，背面被盖住，这 4 个脚就焊不到了。
>
> 正确顺序：
> ```
> ① 二极管  →  ② 排针（焊正面）  →  ③ 飞线/电池
>          →  ④ 轴体（焊背面）  →  ⑤ 最后装主控（从下面焊主控自己的焊盘）
> ```
> 主控的焊点在**它自己的焊盘那一面（朝下）**，最后装、从下面焊，全程可达 ✓
>
> **② 回车第2轴要剪掉定位脚。**
>
> 那一颗轴体的定位脚孔**打不出来** —— 它的 4 个旋转角我都试过了，总有一条腿
> 要么撞上主控左排的焊盘（两者中心只差 4.03mm，而轴体脚伸到 ±5.90mm），
> 要么跑到板外。所以板上**只给了它 3 个孔**。
>
> → 装之前用斜口钳**把中间那条塑料定位脚剪掉**，靠另外 2 个电气脚 + 定位板卡扣固定。
> （停止键已通过旋转 270° 解决，4 个孔齐全，不用剪。）

### ① 12 只二极管（正面，卧式贴板）

先把引脚弯成卧式（跨距 7.62mm），插进孔位再焊。**色环端朝左（x 小的一侧）**。

| 位号 | 键 | 中心坐标 (x, y) mm | 孔距板左下角 |
|---|---|---|---|
| D1 | PERM | (6.0, 16) | 走廊1 |
| D2 | UP | (16.5, 16) | |
| D3 | MODEL | (27.0, 16) | |
| D4 | CMD | (47.26, 16) | |
| D5 | STOP | (57.58, 16) | |
| D6 | APPROVE 拨杆 | (67.9, 16) | 阳极→COL6，阴极→APPROVE_MID |
| D7 | LEFT | (6.0, 34) | 走廊2 |
| D8 | DOWN | (16.5, 34) | |

定位技巧：每只二极管跨在孔位左右各 3.81mm 处（用 `pcb/placement.csv` 核对），先焊一只脚，确认卧平再焊另一只。

### ② 主控排针（正面，26 孔 = 13 × 2）

> ⚠️ **2026-10-11 更正：一排是 13 个脚，不是 12 个。**
> 第一版 PCB 按 12 孔（跨距 27.94）打的，而实物是 13 脚（跨距 30.48）——
> 每个孔都偏 1.27mm、还少一个孔，主控根本插不上去。**那一版已作废重投。**
> 现在的板子：孔 y 从 **15.26 到 45.74**（跨距 30.48 = 12 × 2.54）。

1. 把 26 根排针插进 PCB 的两列孔（x=80.97 左列 / 96.21 右列）
   ⚠️ **胶条朝背面（贴 PCB 底面）插**：JP1 左列与 ENTER 第二轴、VOICE 的轴体底座（13.95 宽，x 78~92）投影重叠，胶条若贴正面会把轴体顶住装不平。剪去胶条用散针直焊也可以
   💡 推荐直接**剪掉胶条**：板下净高 5.0mm，胶条 2.5 + 主控 3.2 = 5.7 会顶外壳底板；剪掉后主控贴板底占 3.2 < 5.0 ✓。排针金针本身从轴体底面镂空区穿过（距轴心 4.0~6.6mm，凸台半径 2.4、内壁 5.98），不冲突
2. **把主控套在排针上**（主控元件面朝下对齐后），用胶带固定主控与 PCB 垂直
3. 先焊对角 2 个针 → 检查主控是否垂直 → 再焊完其余
4. 引脚对照（**USB 端 = pad1**，自 USB 端往下数，共 13 脚）：

| JP1 左列 (x=80.97) | net | JP2 右列 (x=96.21) | net |
|---|---|---|---|
| pad1 GND | GND | pad1 **B+** | —（电池直焊主控背面） |
| pad2 D1 | — | pad2 RAW | — |
| pad3 D0 | — | pad3 GND | GND |
| pad4 GND | GND | pad4 **RST** | RST（复位按钮） |
| pad5 GND | GND | pad5 VCC | — |
| pad6 D2 | — | pad6 D21 | — |
| pad7 D3 | — | pad7 D20 | — |
| pad8 **D4** | **ROW1** | pad8 D19 | — |
| pad9 **D5** | **ROW2** | pad9 D18 | — |
| pad10 **D6** | **ROW3** | pad10 **D15** | **RGB_DIN**（预留） |
| pad11 **D7** | **COL1** | pad11 **D14** | **COL6** |
| pad12 **D8** | **COL2** | pad12 **D16** | **COL5** |
| pad13 **D9** | **COL3** | pad13 **D10** | **COL4** |

> **怎么认 pad1**：USB-C 座所在的那条**短边**就是 pad1 端；金属壳会压住头 3 个焊盘
> （左排 GND/D1/D0，右排 B+/RAW/GND），所以从上往下第 1 个能看清的丝印
> 左边是 `RST`、右边是 `GND` —— 这是正常的。
>
> ⚠️ 上表按官方引脚图逐脚核对过，但**焊前请再拿实物对一次**（批次不同丝印可能有差异）。

### ③ 飞线焊盘（正面，Ø1.5 孔）

| 位号 | 位置 (x, y) | 接什么 |
|---|---|---|
| LEV1 | (89, 16.5) | 拨杆**常开端 NO**（net APPROVE_MID） |
| LEV2 | (85.5, 15.8) | 拨杆**公共端 COM**（net ROW1） |
| RST1 | (74, 17) | 复位按钮一脚（net RST） |
| GND1 | (78, 17) | 复位按钮另一脚（net GND） |
| RGB1 | (76, 22) | D15 预留（net RGB_DIN，可不接） |
| PWR1/PWR2 | (3, 23)/(3, 27) | 电源开关两脚（飞线转接，无网络） |

电池飞线：电池 **红线 → 电源开关 → 主控 B+**，电池 **黑线 → 主控 B−**（主控板上自带 B+/B− 焊盘，不经过 PCB 走线）。

### ④ 14 个轴体（最后焊，保证对齐）

1. 把轴体全部卡进**定位板**（卡扣朝下）
2. 定位板+轴体整体对准 PCB（轴体 3 根脚穿进 PCB 孔：2 小 1 大）
3. 检查每个轴的 2 个电气脚都露出 PCB 背面 → 焊正面
4. 焊完拆下定位板前，逐个按压测试手感

⚠️ 两个轴**没有小定位孔**（下排最右 STOP、中排最右 ENTER 第二轴）——设计如此，定位脚悬空，不影响。

### ⑤ 拨杆开关（装壳时）

拨杆本体装在外壳右壁孔位（缺口处），两根引线分别焊到 LEV1/LEV2。**不分正负**（SPDT 单刀双掷），但 COM/NO 不能接反：用万用表通断档确认——拨杆拨向一侧时 COM-NO 导通的那对。

## 2. 焊后检查（上电前）

1. **目检**：所有焊点饱满光亮、无虚焊连锡；二极管色环方向全部一致
2. **万用表通断**（不接电）：
   - 每个轴：按住轴心，两个电气脚应导通
   - 每条行线/列线：同网络焊盘两两导通（对照 `pcb/netlist.md`）
   - 电源：主控 B+ 与 GND **不导通**（防电池反接短路）
3. **首次上电**：只插 USB-C（不接电池），连电脑 → 设备应枚举出键盘（烧录固件后）
