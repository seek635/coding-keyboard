# ClaudePad 焊接指南

> 板子已到货并验收通过后，按本文档焊接。焊接对照数据来自 `pcb/netlist.md`（自动生成，勿手改）。

## 0. 焊前准备

**工具**：电烙铁（350℃±10℃，细尖头）、焊锡 0.6mm、助焊剂、镊子、斜口钳、万用表（通断档）

**元件清点**（对应 `docs/新手采购清单.md`）：

| 元件 | 数量 | 焊在哪 |
|---|---|---|
| 1N4148 二极管（DO-35 玻璃管） | 12 | 正面，卧式 |
| 主控 NoLogo ProMicro NRF52840 | 1 | 背面（直焊排针） |
| 排针 2.54mm（1×13）×2 或剪配 | 26 针 | 正面孔位 |
| SPDT 拨动开关 | 1 | 外壳右壁（引线焊 PCB） |
| 电源开关 / 复位按钮 | 各 1 | 飞线焊盘 |
| 轴体 Choc V2 红轴 | 14 | 正面 |
| 电池（带线） | 1 | 飞线到主控 B+/B− |

**极性铁律**：二极管玻璃管**有色环的一端 = 阴极（K）= 朝轴体那一侧**（网表里的 MID 节点），
无环端 = 阳极（A）= 接**列线**（COL）。12 只必须同一方向，插反不烧但按键读不出来。

> ★ 2026-10-11 修正（重要）：二极管**不是**直接跨在列线和行线上。
> 正确回路是**串联**：`列 COL ── A▷|── K ── MID ── 轴体pad1 ──[按下]── pad2 ── ROW 行`
> 之前生成器把两者接成了**并联**（二极管与轴体都跨在 COL/ROW 上）——
> 那样驱动任一列都会经二极管直接灌通行线，**该列所有按键恒为"按下"，键盘不可用**。
> 现在板上每个矩阵位置多了一条 `MID_R?C?` 网络（轴体与二极管之间的短线）。

## 1. 焊接顺序（由矮到高）

> ## ⚠️ 2026-10-11 三个必须知道的改动
>
> **① 顺序改了：先焊轴体，最后装主控。**
>
> 原顺序是「② 排针+主控 → ④ 轴体」，但**回车第2轴的 4 个孔正好在主控正下方**。
> 主控一旦装上，背面被盖住，这些脚就焊不到了。
>
> 正确顺序：
> ```
> ① 二极管  →  ② 排针（焊正面）  →  ③ 飞线/电池
>          →  ④ 轴体（焊背面）  →  ⑤ 最后装主控（从下面焊主控自己的焊盘）
> ```
> 主控的焊点在**它自己的焊盘那一面（朝下）**，最后装、从下面焊，全程可达 ✓
>
> **② 14 颗轴体全部是完整 4 孔，不用剪任何一条腿。**
>
> （这一条中途变过：回车第2轴一度无解、要剪定位脚。后来把它**转 90°**、
> 主控左排孔挪到 78.03 才腾出位置 —— 详见 `pcb/placement.csv` 与 `tools/gen_kicad.py` 头注释。）
>
> **③ 最下面那行（空格那行）4 颗键贴左排**：空格跨列 **1-3**、语音键在**列 4**，
> 列 5（x=85）空出 —— 主控上方不再压任何轴体。
>
> ⚠️ 板子尺寸是 **99 × 50**（不是更早那版的 98 × 50），缺口深度 9mm。

| 位号 | 键 | 中心坐标 (x, y) mm | 孔距板左下角 |
|---|---|---|---|
| D1 | PERM | (6.0, 16) | 走廊1 |
| D2 | UP | (16.5, 16) | |
| D3 | MODEL | (27.0, 16) | |
| D4 | CMD | (47.26, 16) | |
| D5 | STOP | (57.58, 16) | |
| D6 | APPROVE 拨杆 | (67.9, 16) | 阳极→COL6，阴极→APPROVE_MID |
| D7 | LEFT | (6.0, 34) | 走廊2 |
| D8 | DOWN | (16.5, 34) | |
| D9 | RIGHT | (27.0, 34) | |
| D10 | ENTER | (57.58, 34) | |
| D11 | SPACE | (47.26, 34) | |

定位技巧：每只二极管跨在孔位左右各 3.81mm 处（用 `pcb/placement.csv` 核对），先焊一只脚，确认卧平再焊另一只。
**左端 = 色环 = 阴极 K**（朝轴体一侧的 MID 网络）｜**右端 = 阳极 A**（接列线）。

### ② 主控排针（正面，26 孔 = 13 × 2）

> ⚠️ **2026-10-11 更正：一排是 13 个脚，不是 12 个。**
> 第一版 PCB 按 12 孔（跨距 27.94）打的，而实物是 13 脚（跨距 30.48）——
> 每个孔都偏 1.27mm、还少一个孔，主控根本插不上去。**那一版已作废重投。**
> 现在的板子：孔 y 从 **14.82 到 45.30**（跨距 30.48 = 12 × 2.54，USB 端在 y=45.30）。

1. 把 26 根排针插进 PCB 的两列孔（x=**78.03** 左列 / **93.27** 右列）
   ⚠️ **胶条朝背面（贴 PCB 底面）插**：JP1 左列与 ENTER 第二轴的轴体底座（13.95 宽，x 78~92）投影重叠，胶条若贴正面会把轴体顶住装不平。剪去胶条用散针直焊也可以
   💡 推荐直接**剪掉胶条**：板下净高 5.0mm，胶条 2.5 + 主控 3.2 = 5.7 会顶外壳底板；剪掉后主控贴板底占 3.2 < 5.0 ✓。排针金针本身从轴体底面镂空区穿过（距轴心 4.0~6.6mm，凸台半径 2.4、内壁 5.98），不冲突
2. **把主控套在排针上**（主控元件面朝下对齐后），用胶带固定主控与 PCB 垂直
   ⚠️ 主控最后装：先焊轴体（第 ④ 步），主控第 ⑤ 步装
3. 先焊对角 2 个针 → 检查主控是否垂直 → 再焊完其余
4. 引脚对照（**USB 端 = pad1**，自 USB 端往下数，共 13 脚）：

| JP1 左列 (x=78.03) | net | JP2 右列 (x=93.27) | net |
|---|---|---|---|
| pad1 GND | GND | pad1 **B+** | —（电池直焊主控背面） |
| pad2 D1 | — | pad2 RAW | — |
| pad3 D0 | — | pad3 GND | GND |
| pad4 GND | GND | pad4 **RST** | RST（复位按钮） |
| pad5 GND | GND | pad5 VCC | — |
| pad6 D2 | — | pad6 D21 | — |
| pad7 D3 | — | pad7 D20 | — |
| pad8 **D4** | **ROW1** | pad8 D19 | — |
| pad9 **D5** | **ROW2** | pad9 D18 | — |
| pad10 **D6** | **ROW3** | pad10 **D15** | **RGB_DIN**（预留） |
| pad11 **D7** | **COL1**（空格 3 轴） | pad11 **D14** | **COL6**（拨杆） |
| pad12 **D8** | **COL2** | pad12 **D16** | **COL5**（停止） |
| pad13 **D9** | **COL3** | pad13 **D10** | **COL4**（回车 2 轴 + 语音） |

> **怎么认 pad1**：USB-C 座所在的那条**短边**就是 pad1 端；金属壳会压住头 3 个焊盘
> （左排 GND/D1/D0，右排 B+/RAW/GND），所以从上往下第 1 个能看清的丝印
> 左边是 `RST`、右边是 `GND` —— 这是正常的。
>
> ⚠️ 上表按官方引脚图逐脚核对过，但**焊前请再拿实物对一次**（批次不同丝印可能有差异）。

### ③ 飞线焊盘（正面，Ø1.5 孔）

| 位号 | 位置 (x, y) | 接什么 |
|---|---|---|
| LEV1 | (89, 16.5) | 拨杆**常开端 NO**（net APPROVE_MID） |
| LEV2 | (85.5, 15.8) | 拨杆**公共端 COM**（net ROW1） |
| RST1 | (74, 17) | 复位按钮一脚（net RST） |
| GND1 | (74, 13) | 复位按钮另一脚（net GND） |
| RGB1 | (75.5, 22) | D15 预留（net RGB_DIN，可不接） |
| PWR1/PWR2 | (3, 23)/(3, 27) | 电源开关两脚（飞线转接，无网络） |

> 复位按钮两个焊盘做成**同列、间距 4mm**，正好配 6×6 轻触开关的两个引脚。

电池飞线：电池 **红线 → 电源开关 → 主控 B+**，电池 **黑线 → 主控 B−**（主控板上自带 B+/B− 焊盘，不经过 PCB 走线）。

### ④ 14 个轴体（先焊，保证对齐）

1. 把轴体全部卡进**定位板**（卡扣朝下）
2. 定位板+轴体整体对准 PCB（轴体 3 根脚穿进 PCB 孔：2 小 1 大）
3. 检查每个轴的 2 个电气脚都露出 PCB 背面 → 焊正面
4. 焊完拆下定位板前，逐个按压测试手感

✅ **14 颗轴体全部是完整 4 孔**（2026-10-11 起不再有省孔）：每颗都有 2 个电气孔 +
1 个定位孔 + 1 个中心孔，不用剪任何一条腿。

> ⚠️ 这三个轴体是**转着装的**，别装反：**STOP（下排最右）270°**、
> **ENTER 第二轴（中排最右）90°**、**VOICE（空格行第 4 颗）180°**。
> 定位板开孔是方的、转哪个角度都进得去，但**孔位对不对得上**取决于角度。

### ⑤ 拨杆开关（装壳时）

拨杆本体装在外壳右壁孔位（缺口处），两根引线分别焊到 LEV1/LEV2。**不分正负**（SPDT 单刀双掷），但 COM/NO 不能接反：用万用表通断档确认——拨杆拨向一侧时 COM-NO 导通的那对。

## 2. 焊后检查（上电前）

1. **目检**：所有焊点饱满光亮、无虚焊连锡；二极管色环方向全部一致
2. **万用表通断**（不接电）：
   - 每个轴：按住轴心，两个电气脚应导通
   - ★ **列线 ↔ 行线 必须不导通**（所有轴都没按下的状态下）。
     这一条就是用来抓「二极管与轴体并联」那个致命错误的：
     如果某一列和某一行在没按键时就导通，说明二极管接成了并联（或者那只二极管短路），
     上电后该列按键会**恒为按下**。
   - 每个 `MID_R?C?` 节点：轴体一只脚 ↔ 对应二极管的一端 导通（对照 `pcb/netlist.md` 第 3 张表）
   - 每条行线/列线：同网络焊盘两两导通（对照 `pcb/netlist.md`）
   - 电源：主控 B+ 与 GND **不导通**（防电池反接短路）
3. **首次上电**：只插 USB-C（不接电池），连电脑 → 设备应枚举出键盘（烧录固件后）
