## 四、工具（已有则忽略）

- 可调温电烙铁 + 尖头（XIAO 排针和 BAT 细线需要尖头）
- 0.6mm 焊锡丝、助焊剂、吸锡带
- 斜口钳、镊子、美纹纸/高温胶带
- 万用表（焊接后必测短路）
- USB-C 数据线（刷机必须用数据线）
- 台灯/放大镜

> ⚠️ 锂电安全：必须使用**带保护板**的电池；充电时有人看管；不要让电池被螺丝或外壳挤压；焊接电池线前先拔 JST。

## 五、PCB 网络一览

完整网络表、焊接顺序和 XIAO 电池线见 [pcb.md](pcb.md)。核心连接：

| 信号 | XIAO 引脚 | PCB 网络 |
|---|---|---|
| 行 R0 | D0（pad 1） | ROW0 |
| 行 R1 | D1（pad 2） | ROW1 |
| 行 R2 | D2（pad 3） | ROW2 |
| 列 C0 | D6（pad 7） | COL0 |
| 列 C1 | D7（pad 8） | COL1 |
| 列 C2 | D8（pad 9） | COL2 |
| 列 C3 | D9（pad 10） | COL3 |
| 列 C4 | D10（pad 11） | COL4 |

- ENTER（SW10+SW11）并联，共用 D10 → ROW2。
- SPACE（SW12+SW13+SW14）并联，共用 D11 → ROW2。
- 电池：XIAO 背面 BAT+/BAT− → 两根细线（模块右侧引出）→ BAT1 焊盘（JST 旁，不在主板下方）→ JST（pin1 +、pin2 −）。

## 七、下单前检查

1. 主控：XIAO nRF52840 标准版，确认 USB-C、RESET、背面 BAT 焊盘；ZMK 板名 `xiao_ble`。另配 2× 1×7 2.54mm 排针，穿孔焊接。
2. PCB：**2 层**、90×76mm、1.6mm；XIAO 位置是 14 个 1.0mm 穿孔焊盘；Gerber 在 `pcb/output/gerbers/`；不要选错层数。
3. 先打印 **test_coupon.stl**，确定 `SWITCH_PLATE_GAP` 后再打印底座/定位板。
4. 键帽：Choc V2 / 18×17mm；2u、3u 先确认有货。
5. 二极管：DO-35 直插；色环方向按 PCB 背面短横线。
6. 电池带保护板，尺寸约 30×20×3mm（302030），JST 极性 pin1 +、pin2 −。
7. 外壳控制器仓是敞开的，方便刷机和按 RESET；XIAO 用排针抬高，后壁 USB-C 开口已上移到 z≈10.5–14.3，不装电源开关。
