# ClaudePad 打样下单指南（嘉立创 JLC）

> 打样文件已打包：`pcb/fabrication/claudepad-jlc.zip`（Gerber 7 层 + 钻孔 + IPC-D-356 网表）
> 生成命令：`kicad-cli pcb export gerbers/drill/ipcd356`（2026-09-28，基于 DRC 全绿版板文件）

## 一、下单参数（嘉立创官网 → PCB 智能下单 → 上传 zip 后逐项核对）

| 参数 | 选什么 | 说明 |
|---|---|---|
| 板子尺寸 | 98 × 50 mm（自动识别） | 单板，**不拼板** |
| 板层数 | **2** | 双面板 |
| 板厚 | **1.6 mm** ★ | **凯华 datasheet 明确要求 1.6mm**（轴体引脚长度按此设计），选错轴体插不到底 |
| 数量 | 5 | 嘉立创最低起订量 |
| 阻焊颜色 | 任意（绿色最便宜） | |
| 丝印颜色 | 白色 | 阻焊选绿/红/蓝时配白字；选白油需配黑字 |
| 表面处理 | **有铅喷锡（HASL）** | 最便宜够用；预算充足可选沉金（插拔更顺滑） |
| 铜厚 | 1 oz（默认） | |
| 过孔处理 | **盖油（覆盖）** | 板上仅 2 个过孔，盖油防止意外短路 |
| 飞针/电测 | 可不选 | 已附带 IPC-D-356 网表（claudepad-d356a.txt），需要时再补 |
| 半孔/挖槽 | 无需特殊工艺 | 右下角缺口是普通板边开槽，不加钱 |

## 二、下单步骤

1. 打开 jlc.com → 注册/登录 → 首页「PCB 下单」
2. 把 `pcb/fabrication/claudepad-jlc.zip` 拖进上传框 → 系统自动解析尺寸/层数
3. 按上表逐项核对（尤其 **板厚 1.6mm**）
4. 付款下单（5 片学生价约 10~30 元，普通物流另计）

## 三、到货核对清单

- [ ] 板厚 1.6mm（卡尺量）
- [ ] 右下角缺口位置、深度 8mm 对（对照板上丝印）
- [ ] 14 个轴体孔位：每轴 2 小孔 + 1 中心大孔（下排最右、中排最右 2 轴无小定位孔——设计如此）
- [ ] 24 个主控排针孔两列对齐
- [ ] 走线无断路（可对照 `pcb/fabrication/claudepad-d356a.txt` 或 KiCad 3D 视图）

## 四、到货后返回项目继续

焊接 → 固件烧录 → 装壳。参考 `docs/新手采购清单.md` 的焊接章节。
