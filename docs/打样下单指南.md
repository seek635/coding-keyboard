## 一、下单参数（嘉立创官网 → PCB 智能下单 → 上传 zip 后逐项核对）

| 参数 | 选什么 | 说明 |
|---|---|---|
| 板子尺寸 | 99 × 50 mm（自动识别） | 单板，**不拼板** |
| 板层数 | **2** | 双面板 |
| 板厚 | **1.6 mm** ★ | **凯华 datasheet 明确要求 1.6mm**（轴体引脚长度按此设计），选错轴体插不到底 |
| 数量 | 5 | 嘉立创最低起订量 |
| 阻焊颜色 | 任意（绿色最便宜） | |
| 丝印颜色 | 白色 | 阻焊选绿/红/蓝时配白字；选白油需配黑字 |
| 表面处理 | **有铅喷锡（HASL）** | 最便宜够用；预算充足可选沉金（插拔更顺滑） |
| 铜厚 | 1 oz（默认） | |
| 过孔处理 | **盖油（覆盖）** | 板上 3 个过孔，盖油防止意外短路 |
| 飞针/电测 | **建议勾上**（约 +10 元） | 已附带 IPC-D-356 网表（claudepad-d356a.txt）；这一版线路密，值得花这个钱 |
| 半孔/挖槽 | 无需特殊工艺 | 右下角缺口是普通板边开槽，不加钱 |
| 阻抗/特殊工艺 | 都不需要 | 普通双面板 |

## 二、下单步骤

1. 打开 jlc.com → 注册/登录 → 首页「PCB 下单」
2. 把 `pcb/fabrication/claudepad-jlc.zip` 拖进上传框 → 系统自动解析尺寸/层数
   （应识别为 **99 × 50 mm、2 层**；若识别成其它尺寸，说明传错文件了）
3. 按上表逐项核对（尤其 **板厚 1.6mm**）
4. 付款下单（5 片学生价约 10~30 元，普通物流另计）

## 三、到货核对清单

- [ ] 板厚 1.6mm（卡尺量）
- [ ] 外形 **99 × 50**，右下角缺口深度 **9mm** 对（对照板上丝印）
- [ ] 14 个轴体孔位：每轴 **4 个孔**（2 电气 + 1 定位 + 1 中心大孔）—— 2026-10-11 起不再有省孔
- [ ] **26 个主控排针孔**两列对齐（2 × 13，列位 x=78.03 / 93.27）
      ★ 拿主控实物比一下：一排 **13 个脚**，孔距必须对得上。
      第一版按 12 孔打废了 —— 每个孔偏 1.27mm（半个间距），主控插不进去。
- [ ] 铜箔走线完整（对照 `pcb/fabrication/claudepad-F_Cu.gtl` / `B_Cu.gbl` 或 KiCad 3D 视图）
- [ ] ★ **万用表量：列 ↔ 行不导通**（不按键时）。若导通说明二极管与轴体被焊成并联
      （2026-10-11 修掉的老 bug），键盘会「该列按键恒为按下」

## 四、到货后返回项目继续

焊接 → 固件烧录 → 装壳。参考 `docs/新手采购清单.md` 的焊接章节。
