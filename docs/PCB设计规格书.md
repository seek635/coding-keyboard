## 1. 这块板子要做什么

把 11 个轴体 + 1 个审批拨杆 + 1 个主控 + 1 个电池座连起来，装进外壳。

**设计约束（全部来自已确定的结构与固件）**：

| 约束 | 来源 | 值 |
|---|---|---|
| 板子外形 | `params.scad` 的 `PCB_W` / `PCB_H` | 86 × 50 mm |
| 板厚 | `PCB_T` | 1.6 mm |
| 矩阵 | 固件 `claudepad.overlay` | 3 行 × 6 列 |
| 引脚 | 同上 | 行 D4/D5/D6，列 D7/D8/D9/D10/D16/D14 |
| 右侧缺口 | 拨杆本体在壳内的位置 | 深 8 × 长 24 mm |
| 轴体位置 | 定位板轴孔（`params.scad`） | 见 §4 |

## 2. 板子外形

```
        ┌──────────────────────────────────────────────┐
        │                                              │
        │             86.00 × 50.00                    │
        │                                              │┌──┐
        │              主矩阵区                         ││缺│
        │                                              ││口│ 8×24
        │                                              │└──┘
        └──────────────────────────────────────────────┘
```

**右侧缺口**：深 8mm、纵向 24mm，位置对准拨杆。
原因：SPDT 拨杆的**本体在壳内**（拨杆+轴套+螺母在壳外），本体沿轴套方向侵入约 8.5mm。
不给它让位，本体就会压到 PCB 上。

**四角不要放安装孔**：PCB 不靠螺丝固定——它由 14 个轴体「挂」着（轴体卡在定位板上，定位板用 4 颗 M2 螺丝锁在底座上）。
这是键盘的常规做法，PCB 无需额外固定。

## 3. 矩阵接线

完整接线图见 **`pcb/wiring.svg`**（可打印放大），焊接对照表见 **`pcb/netlist.md`**。

### 3.1 二极管方向（关键）

```
固件配置：diode-direction = "col2row"
含义：    二极管阳极接列线，阴极接行线
电流方向：列 → 行
```

每个按键回路：

```
列线 ──▶ 二极管阳极 ──▶ 二极管阴极 ──▶ 轴体 ──▶ 行线
```

**为什么是这个方向**：`col2row` 时列是**输出驱动**（`GPIO_ACTIVE_HIGH`），行是**输入读取**（`GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN`）。二极管必须允许电流从被驱动的列流向被读取的行。

> ⚠️ **接反不会烧，但矩阵完全读不出来。**
> 修正二选一：把所有二极管掉头，或把固件里的 `diode-direction` 改成 `"row2col"`。
> 后者更省事，但以后别人看板子会困惑——建议前者。

### 3.2 引脚分配

| 信号 | 引脚 | 方向 |
|---|---|---|
| ROW1 / ROW2 / ROW3 | D4 / D5 / D6 | 输入（PULL_DOWN） |
| COL1 … COL6 | D7 / D8 / D9 / D10 / D16 / D14 | 输出 |
| RGB 数据 | D15 | 输出 |

> 这套分配必须与 `firmware/boards/shields/claudepad/claudepad.overlay` 一致。
> 改了这边就要改那边，`tools/check_keymap.py` 会检查键位顺序但**不检查引脚**，需人工确认。

### 3.3 大键并联（重要）

回车和空格在定位板上分别开了 2 个和 3 个轴孔（解决长键翘曲）。这些轴体在**电气上并联**：

| 大键 | 轴体数 | 都接到 |
|---|---|---|
| **回车**（2u） | 2 | ROW2 × COL4 |
| **空格**（4u） | 3 | ROW3 × COL1 |

**PCB 上要把这几个轴体的焊盘用铜箔连到同一条行/列线上**，否则会变成多个独立按键。
手焊洞洞板时，就是用一根导线把它们的引脚串起来。

### 3.4 审批拨杆

| 项 | 值 |
|---|---|
| 位置 | 右壁（不在轴体网格里） |
| 接线 | 公共端 → ROW1；常开端 → COL6（D14） |
| 二极管 | **建议串一只 1N4148** —— 拨杆是开关不是轴体，不串可能在多键同按时产生鬼影 |

拨杆是**两态**器件：拨到 ON 时持续接通 ROW1–COL6，固件读到的就是一个「一直按住的 F13」。

## 5. 元件布局

| 元件 | 位置 | 说明 |
|---|---|---|
| 14 个轴体 | 见 §4 | 主矩阵 |
| 14 只 1N4148 | 每个轴体旁 | 建议放在轴体与行线之间，占用小 |
| nice!nano v2 | 右上区域，**直接焊在板上** | 见下 |
| 审批拨杆引线焊盘 | 右侧缺口附近 | 公共端→ROW1，常开端→COL6 |
| 电池座（JST 1.25） | 左侧空区 | 电池在 PCB 正下方，走线穿过 |
| 电源开关焊盘 | 左侧 | 串在电池正极与主控之间 |
| 复位按钮焊盘 | 主控旁 | 并联到 RST |
| WS2812 | 沿轴体分布 | 数据线 D15 |

### 5.1 主控必须直焊，不能用排母

外壳内腔在 PCB 上方只有 **5.0mm** 净空（= `SWITCH_PLATE_GAP`），而 nice!nano 加上普通排母的高度约 8.5mm，**装不下**。

所以主控必须**直接焊接在 PCB 上**（板对板），或用超矮排针。这是「薄」换来的代价。

主控位置：PCB 右上区域，USB-C 口朝**右侧**，对准外壳右壁的 USB 开孔。

### 5.2 PCB 支撑台位置（与外壳的配合）

外壳里有 4 个矮柱托住 PCB，位置在 **PCB 坐标 (16,16)、(70,16)、(16,34)、(70,34)**。

> ⚠️ 这些位置是**轴体之间的空隙中心**，不是四角。
> 轴体之间只有 `18 − 13.5 = 4.5mm` 空隙，四角正好是轴体塑料脚的位置，支撑台放那里会顶住装不进去。
> 支撑台直径 4.0mm < 4.5mm 空隙。

画 PCB 时**不需要**为它们开孔（支撑台在 PCB 下方，只是托着）。

## 6. 布线规格

| 项 | 建议值 | 理由 |
|---|---|---|
| 铜厚 | 1 oz（35µm） | 常规，够用 |
| 行/列信号线宽 | **0.25 mm** | 信号线电流极小 |
| 电源线宽（3.3V / VBAT） | **0.6 mm** | 主控峰值电流 + RGB |
| GND 线宽 | **0.6 mm** 或铺铜 | 回流路径 |
| 线间距 | ≥ 0.2 mm | 嘉立创常规工艺 |
| 过孔 | 0.3/0.6 mm | 常规 |
| 层数 | **2 层** | 足够，成本低 |

**布线要点**：

1. **行线/列线尽量走到底层**，顶层留给轴体焊盘和元件
2. **WS2812 的数据线串一颗 100–300Ω 电阻**（靠主控端），防振铃
3. **RGB 电源加 100µF 电解 + 0.1µF 陶瓷**去耦，否则灯珠闪烁
4. 天线区（nice!nano 的板载天线下方）**不要铺铜、不要走线**，否则蓝牙距离骤降
5. 大键并联的几个轴体，用同一根粗一点的线（0.4mm）串起来

## 9. 打板前必做的三件事

1. **先打外壳和定位板，实测 `SWITCH_PLATE_GAP`**
   （用 `cad/test_coupon.scad` 校准件，15 分钟）
   这个值决定 PCB 上轴体焊盘与定位板的相对高度关系，虽然 PCB 本身不受影响，
   但**主控高度**受它约束——如果实测值 < 3.7mm，主控方案要改。

2. **确认拨杆实物尺寸**
   轴套直径/长度、面板尺寸、**本体侵入深度**。本体侵入 > 8.5mm 的话，缺口要加深。

3. **确认 nice!nano 的封装尺寸**
   17.8 × 33mm 是标称值，实物可能有偏差。特别是 USB-C 口的位置——它要和外壳右壁的开孔对齐。

## 10. 手焊洞洞板（不用打 PCB 的路线）

如果想先验证电路再打板，按 `pcb/wiring.svg` 在洞洞板上焊：

**需要的洞洞板**：至少 90 × 54 mm（留余量）

**步骤**：

1. 先焊 14 只二极管，**统一方向**（阳极朝列）
2. 用裸铜线沿列走 6 条、沿行走 3 条，构成矩阵
3. 每个轴体位置焊两个排针座（或用飞线直接连轴体）
4. 大键的多个轴体，用一根线把它们的引脚串起来
5. 最后接主控、拨杆、电池座

> 洞洞板版本的轴体无法插进去固定，只能**用飞线把轴体引出来**，或者先不装轴体、用镊子短接焊盘测试固件。

## 12. 本规格书的边界

**包含**：板子外形、矩阵接线、封装坐标、元件布局、布线规格、与外壳的配合。

**不包含**：
- ❌ **具体 PCB 布局文件**（KiCad 工程）——本文件给的是**设计规格与坐标**，画板需要你在 KiCad 里落地
- ❌ **原理图符号库**——直接用 KiCad 自带的 Switch/Diode 符号即可
- ❌ **RGB 灯珠的具体数量与排布**——取决于你想要的灯效，见 PRD 第 8 章

**未验证项**：
- 本规格书的数据来自 `params.scad` 与两个开源封装库，**逻辑与坐标已交叉验证**
- 但**没有生成实际的 PCB 文件并用 DRC 检查过**，也没有打样实测
- 首次画板后，请用 KiCad 的 DRC 跑一遍，并对照 §11 清单人工确认

## 13. 能买现成的 PCB 吗？

**结论：不能。** 而且原因比"布局特殊"更根本。

### 13.1 根本障碍：我们的轴体不在标准网格上

标准宏键盘 PCB 是**均匀网格**——每 18mm（Choc）或 19.05mm（MX）一个格点，每个格点一个独立矩阵节点。

本设计的轴体坐标（PCB 原点在左下，单位 mm）：

| 键 | 坐标 |
|---|---|
| 第 1 行 5 键 | x = 7, 25, 43, 61, 79（y=7） |
| 第 2 行 3 键 + 回车 2 轴 | x = 7, 25, 43, 61, 79（y=25） |
| 空格 3 轴 | **x = 7, 34, 61**（y=43） |
| 语音 | x = 79（y=43） |

网格线是 **7 / 25 / 43 / 61 / 79**。而空格的中间那根轴在 **x = 34** —— **它不在网格上**。

这不是失误：4u 键跨列 1–4，跨度 72mm，三点对称支撑落在 1/6、3/6、5/6 处，中点正好是跨度中心。
**任何均匀网格的 PCB 都放不下它。**

### 13.2 其余三个不匹配

| 维度 | 本设计 | 市面现成宏键盘 PCB |
|---|---|---|
| 主控 | nice!nano（nRF52840）+ BLE | 多为 Pro Micro（ATmega32u4）+ USB 有线 |
| 固件 | ZMK | 多为 QMK（引脚与配置不通用） |
| 轴体 | Kailh Choc 矮轴，18mm 键距 | 多为 MX，19.05mm 键距 |
| 板形 | 86 × 50，右侧 8×24 拨杆缺口 | 尺寸与缺口都对不上 |

### 13.3 那怎么办？三条实际路径

| 路径 | 说明 | 适用时机 |
|---|---|---|
| **A. 洞洞板手焊** | 用 §10 的接线图 + `pcb/wiring.svg` 直接焊。零等待、成本最低 | **原型验证阶段（推荐先走这条）** |
| **B. 拿开源设计改** | 立创开源硬件平台（oshwhub）上有现成的**无线矮轴小键盘**项目，已解决最难的部分：nice!nano 引脚、电池接口、充电电路、电源开关、Choc 轴座封装、ZMK/RMK 固件。只需改布局 + 加拨杆缺口。**详细方案见 `docs/PCB改板方案.md`** | 想要正式 PCB 但不想从零画 |
| **C. 从零画板打样** | 本规格书已给全部网表与坐标，2 层板，嘉立创 5 片起 | 布局定稿后 |

**参考开源项目**（oshwhub 搜索可得，均为无线矮轴 + nice!nano）：
- **EPPad** —— 无线小键盘，凯华/佳达隆两种轴座孔，资料最全（原理图+PCB+BOM+结构）→ **推荐作底板**
- **TK13** —— 凯华矮轴，结构简单，但无 BOM

> ⚠️ 这些项目**布局都与本设计不同**，只能拿来复用「主控电路 + 轴座封装 + 固件框架」，
> 布局必须自己改。**具体怎么做见 `docs/PCB改板方案.md`** —— 含复用清单、
> 三个必先解决的冲突（热插拔高度冲突 / 板形 / 离格轴）、分步流程与验证清单。

### 13.4 为什么建议先洞洞板

1. **布局还没经过实物验证** —— 大键手感、拨杆位置、整体厚度都只是纸面设计
2. **洞洞板改起来零成本**，PCB 改一次要等一周
3. 项目本来就是分步推进的（`docs/采购清单.md` 第 1 步 → 第 3 步）

**顺序建议**：校准试件 → 洞洞板原型 → 实机验证手感 → 定稿布局 → 打样 PCB。

## 14. ★ 已发现的阻塞问题：主控放不下

**2026-09-15 发现。** 这一条影响**所有**路径（买现成 / 改开源 / 自己画）——
不是 PCB 的问题，是**布局本身没有给主控留位置**。

### 14.1 问题

主控 nice!nano 是 **17.8 × 33.0 mm**，而板面只有 **86 × 50 mm**，
上面已经摆了 **14 个轴体**（本体 13.5mm 见方，占 2550 mm²，板面共 4300 mm²）。

穷举板面所有位置（步长 0.5mm）：

| 检查 | 结果 |
|---|---|
| 当前设计位置（PCB 坐标 65.2, 14.0） | ❌ 与轴体重叠 **322.52 mm²** |
| 板面上零重叠的位置数 | **0 个** |

重叠的 4 个轴体：

| 键 | 轴心 | 重叠面积 |
|---|---|---|
| 回车（第 2 轴） | (79, 25) | ~146 mm²（几乎整个轴体） |
| 语音 | (79, 43) | ~116 mm²（几乎整个轴体） |
| 回车（第 1 轴） | (61, 25) | ~34 mm² |
| 空格（第 3 轴） | (61, 43) | ~27 mm² |

**根因**：3×5 网格在 18mm 键距下需要 **90 × 54 mm** 才排得开，
而 PCB 只有 86 × 50 —— 轴体本体几乎贴到板边（四边各余 0.25mm），**没有任何连续空位**。

> 这条已固化为 `tools/check_dims.py` 第 11 节的两项自动检查，不会再被漏掉。

### 14.2 解决方案（推荐：主控移到 PCB 背面）

PCB 下方有 **5.0 mm** 层高，主控厚 **3.2 mm** —— **放得下**。

背面布局（PCB 坐标）：

```
        ┌────────────────────────────────────────┐
        │                                        │
        │        电池 30×40（居中偏左）           │
        │      x 30.55~60.55  y 7.55~47.55       │
        │                          ┌───────────┐ │
        │                          │  主控      │ │
        │                          │ 17.8×33   │ │
        │                          │x68~85.8   │ │
        │                          │y8.5~41.5  │ │
        └──────────────────────────┴───────────┴─┘
```

**推荐位置**：`x = 68.0, y = 8.5`（最靠右，USB-C 朝右壁）

### 14.3 连带要改的三处

| # | 改什么 | 从 | 到 |
|---|---|---|---|
| 1 | **右侧支撑台** | x = 70（会被主控压住） | **x = 52**（合法的轴体间隙中心） |
| 2 | **USB-C 开孔高度** | PCB 上表面 +1.8mm | PCB 下表面 −1.8mm |
| 3 | 天线净空 | 主控正上方禁铺铜 | 改为**主控正下方**（PCB 背面）禁铺铜 |

**支撑台为什么能挪**：合法位置是轴体间隙中心，x ∈ {16, 34, 52, 70}、y ∈ {16, 34}。
把右侧两个从 70 挪到 52 仍在合法集合内，且避开主控（52 < 68）。

### 14.4 备选方案

| 方案 | 做法 | 代价 |
|---|---|---|
| **A. 主控放背面**（推荐） | 见 §14.2 | USB 开孔下移；天线区改到背面 |
| B. 换更小主控 | 用 E73-2G4M08S1E 等模块（约 13×18mm） | 需自己加充放电电路；固件要改引脚 |
| C. 加大板子/外壳 | PCB 加宽到 96mm 以上 | 整机尺寸变大，外壳全部重做 |

**方案 B 的额外好处**：EPPad 作者也提到 nice!nano 多为 2020 年产芯片、**容易坏**，
建议改用 E73 + 自加充放电。如果要走这条路，值得一并考虑。
