# ClaudePad 手工飞线（备用方案）

> **PCB 方案见 [pcb.md](pcb.md)**；本文件只在不想打 PCB、准备直接飞线时使用。
> 物料见 [BOM.md](BOM.md)，键位语义见 [keymap.md](keymap.md)。
> 目标：3×5 矩阵、8 根线、11 个 1N4148、14 颗 Choc V2 轴。无审批拨杆、无电源开关。

## 1. 主控引脚（XIAO 丝印 D 编号）

| 信号 | 引脚 | 焊在 |
|---|---|---|
| R0 | `D0` | 上排 |
| R1 | `D1` | 中排 |
| R2 | `D2` | 下排 |
| C0 | `D6` | 最左列 |
| C1 | `D7` | 第二列 |
| C2 | `D8` | 第三列 |
| C3 | `D9` | 第四列 |
| C4 | `D10` | 最右列 |

XIAO 的 D3/D4/D5 留空不用（D4/D5 是 I2C）。ZMK 里对应 `&xiao_d 0`～`&xiao_d 10`。

主控背面/侧边固定，USB-C 朝外壳后侧。XIAO 的 **USB-C 与 RESET 按键在同一条边**，外壳必须让这两个都能操作。

> XIAO 使用板载 2.4GHz 天线，天线区域下方不要放电池、螺丝或大面积金属。

## 2. 二极管方向（col2row）

每条支路按这个顺序：

```
列线 ── 开关 ──|>|── 行线
               阳极 阴极(色环)
```

- 1N4148 的**色环端是阴极**，必须朝行线。
- 方向接反的键会整列/整行不响应，焊接前先用万用表二极管档确认。
- 总共 11 个二极管，每个电气交点 1 个。

## 3. 矩阵连线

| 键 | 行 | 列 | 接法 |
|---|---|---|---|
| PERM | R0 | C0 | 单轴 + 1 二极管 |
| MODEL | R0 | C1 | 单轴 + 1 二极管 |
| CMD | R0 | C2 | 单轴 + 1 二极管 |
| ↑ | R0 | C3 | 单轴 + 1 二极管 |
| VOICE | R0 | C4 | 单轴 + 1 二极管 |
| STOP | R1 | C0 | 单轴 + 1 二极管 |
| ← | R1 | C2 | 单轴 + 1 二极管 |
| ↓ | R1 | C3 | 单轴 + 1 二极管 |
| → | R1 | C4 | 单轴 + 1 二极管 |
| ENTER | R2 | C0 | **2 个轴并联**，共用 1 二极管 |
| SPACE | R2 | C2 | **3 个轴并联**，共用 1 二极管 |

> `R1/C1` 是空位，不需要接任何线。

### ENTER / SPACE 的并联

- ENTER 2u：两个轴的同一侧引脚全部接到 C0，另一侧全部接到二极管阳极；二极管阴极接 R2。
- SPACE 3u：三个轴同理，全部并在 C2 和 R2 之间。
- 任一轴按下都会闭合同一个交点，所以固件里 Enter / Space 各只占一个键位。

### 行线与列线

- 先把同一行的所有二极管阴极用一根线串起来 → 接对应行引脚。
- 再把同一列的所有开关公共端串起来 → 接对应列引脚。
- 建议行线用黄/绿，列线用红/黑；电池线单独配色。
- 线径 24–26AWG，拐角处留一点余量，避免拉断焊盘。

## 4. 电源

- 电池 `+` → JST-PH 2.0 插头 → XIAO `BAT+`
- 电池 `−` → JST → XIAO `BAT−`
- XIAO 背面是 BAT+/BAT− **焊盘**，没有 JST 座：先把一段 JST 带线焊到焊盘，再插电池。
- **没有电源开关**：日常靠 ZMK 深度睡眠省电；长期存放、运输或需要硬关机时，拔掉 JST 插头。
- 电池必须带保护板；焊接前用万用表确认极性，不要只信线色。
- 先焊矩阵，最后接电池。
- 首次上电前，用万用表测 `BAT+` 与 `BAT−` 之间**不能短路**。
- XIAO 自带 BQ25101 充电芯片，USB-C 插上即可充电；充电电流较小，大容量电池充电会偏慢。

## 5. 焊接后检查

1. **二极管方向**：逐个用万用表二极管档测，正向压降约 0.5–0.7V，反向不通。
2. **矩阵短路**：不按键时，任意行与任意列之间不应导通。
3. **按键响应**：按住某键时，对应行/列导通。
4. **上电**：XIAO 能进 bootloader（双击板上 RESET）、能被系统识别为键盘。
5. 刷入固件后，用在线 keymap tester 或在文本编辑器里逐键检查（方向键、Enter、Space、STOP 的单击/双击/长按）。
6. **上位机联调**：
   - 打开 `python -m claudepad_host status`，能看到当前模型与权限档位。
   - PERM 长按后，终端权限档位回到 Manual/default。
   - MODEL 长按后，模型切到配置里的下一个。
   - 深度睡眠后按任意键能唤醒并重新连接蓝牙。

## 6. 常见问题

| 现象 | 优先检查 |
|---|---|
| 一整行不响应 | 该行引脚/焊点、行线是否断开 |
| 一整列不响应 | 该列引脚/焊点、列线是否断开 |
| 某个键不响应 | 该键二极管方向、轴体引脚、并联线 |
| 某键一直触发 | 行/列短路，或二极管/焊锡搭桥 |
| 电池不耐用 | ZMK 深度睡眠是否开启、蓝牙是否一直连接、电池容量 |
| 蓝牙距离短 | 天线区域被电池/金属遮挡，或主控天线朝向不对 |
