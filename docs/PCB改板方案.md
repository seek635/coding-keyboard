## 1. 为什么选 EPPad

调研过的候选：

| 项目 | 来源 | 布局 | 主控 | 轴体 | 提供什么 | 结论 |
|---|---|---|---|---|---|---|
| **EPPad** | oshwhub | 20 键（4×5） | **nice!nano** / Monkey / TuCore | **凯华/佳达隆矮轴** | 原理图 + PCB + **BOM** + 定位板/底板 + 3D | ✅ **选定** |
| TK13 | oshwhub | 10 键 | nice!nano | 凯华矮轴 | 壳 STEP + 固件，**无 BOM** | 资料太少 |
| sticc14 | GitHub | 3×5 均匀网格 | Pro Micro | MX | KiCad + gerber | ❌ 有线、无大键 |
| 其他 GitHub 宏键盘 | GitHub | — | — | — | 多为**固件配置**，非硬件 | ❌ |

**选 EPPad 的三个理由**：

1. **同时满足「无线 + nice!nano + 凯华矮轴」** —— 这三个条件同时满足的开源项目极少
2. **资料最全** —— 有原理图、PCB 源文件、BOM（含具体型号）、定位板与底板示例
3. **规模最接近** —— 20 键 vs 我们 14 轴，差得不多

> ⚠️ EPPad 作者自己提到：市面 nice!nano 多为 2020 年产芯片，**容易坏**，建议买正品。
> 这一点与本项目 `docs/采购清单.md` 的提醒一致。

## 3. 三个必须先解决的冲突

### 3.1 ★ 不能用热插拔轴座（最硬的约束）

EPPad 用的是**凯华矮轴热插拔轴座**，但我们用不了：

| | 数值 |
|---|---|
| 热插拔轴座在 PCB **下方**凸出 | **2.5 – 3.0 mm** |
| 而 PCB 下方总共只有（`PCB_STANDOFF_H`） | **5.0 mm** |
| 电池已占（`BATT_H` 4.0 + `BATT_TAPE_T` 0.6） | **4.6 mm** |
| 剩余 | **0.4 mm** ← 装不下轴座 |

**结论：必须改成直焊**（轴脚穿过 PCB 后剪平，凸出 < 0.5mm）。

| | 热插拔 | **直焊（采用）** |
|---|---|---|
| 占用 PCB 下方高度 | 2.5–3.0 mm | < 0.5 mm |
| 能否换轴 | 能 | 不能 |
| 焊接难度 | 低 | 中（14 个轴 × 2 脚） |

**代价可接受**：这是把键盘做到 23.1mm 薄必须付的成本。

> 顺带说明：本项目在 `docs/结构设计规格书.md` 里早就按直焊设计，
> 这条冲突是**改板时才会暴露**的 —— 直接照抄 EPPad 会装不进去。

### 3.2 板形与网格尺寸对不上

| | 尺寸 |
|---|---|
| EPPad 的 4×5 网格 | 约 **90 × 72 mm** |
| 本项目的板 | **86 × 50 mm** |

板形必须完全重画。但这不是问题——「改板」的本意就是重画布局。

### 3.3 离格轴（最容易漏的一条）

空格中间那根轴在 **x = 34**，而网格线是 7 / 25 / 43 / 61 / 79 —— **它不在网格上**。

**操作要点**：放置时**关掉网格吸附**（KiCad 里按 `N` 或改 grid 为 0.01mm），
严格照 `pcb/placement.csv` 的坐标放。靠网格吸附会把它吸到 25 或 43，导致定位板孔对不上。

## 4. 分步操作流程

### 第 1 步：拿到 EPPad 工程

1. 打开 EPPad 项目页（立创开源硬件平台，搜索「EPPad」）
2. 点「克隆工程」把工程复制到自己账号
3. 在立创 EDA 编辑器里打开，或导出为 KiCad 格式

### 第 2 步：建新板并改外形

- 板外形改成 **86 × 50 mm**
- 右侧开缺口 **深 8 × 长 24 mm**，纵向位置对准拨杆（见 `docs/PCB设计规格书.md` §2）
- 板厚 1.6mm，2 层

### 第 3 步：照坐标表放轴体

打开 `pcb/placement.csv`，逐行放 14 个轴体：

```
ref,type,label,matrix,x_mm,y_mm,x_kicad,y_kicad,rotation,note
SW1,switch,PERM,ROW1xCOL1,7.00,7.00,7.00,43.00,0,PERM
...
SW12,switch,SPACE,ROW3xCOL1,34.00,43.00,34.00,7.00,0,SPACE（2/3 并联）
...
```

**注意**：CSV 给了两套坐标
- `x_mm / y_mm` —— 本设计坐标系（板左下角为原点，Y 向上）
- `x_kicad / y_kicad` —— KiCad 坐标系（Y 向下），`y_kicad = 50 − y_mm`

**放之前先确认你的 KiCad 原点设在哪**，别混用。

### 第 4 步：放二极管

14 个 1N4148（0805 贴片）。方向**必须**：**阳极接列线、阴极接行线**（`col2row`）。

> 接反了不会烧，但矩阵读不出来 —— 排查很痛苦，建议放之前先在纸上画一遍。

### 第 5 步：移植 nice!nano 电路

从 EPPad 复制：nice!nano 封装、电池接口、电源开关、复位按钮。
**但把热插拔轴座换成直焊焊盘。**

### 第 6 步：接矩阵

按本项目的 `pcb/wiring.svg` 接：

| 网络 | 引脚 |
|---|---|
| 行 ROW1 / ROW2 / ROW3 | D4 / D5 / D6 |
| 列 COL1–COL5 | D7 / D8 / D9 / D10 / D16 |
| COL6（拨杆） | D14 |

**大键并联**（关键）：
- 回车 2 轴 → 同一矩阵点 **ROW2 × COL4**
- 空格 3 轴 → 同一矩阵点 **ROW3 × COL1**

### 第 7 步：布线

- 信号线 **0.25 mm**，电源 **0.5 mm**
- 2 层，背面铺地
- 天线区域（nice!nano 的板载天线下方）**禁止铺铜**

### 第 8 步：DRC → 出 gerber → 打样

对照 §6 清单人工确认后，导出 gerber 送嘉立创。

## 5. 坐标数据

`pcb/placement.csv` 由 `tools/gen_pcb.py` 从 `cad/lib/params.scad` 生成，
**改尺寸后重跑一次即可同步**：

```bash
python tools/gen_pcb.py
```

14 个轴体的完整坐标见该文件。核心规律：

| 行 | 轴体 x 坐标 | y |
|---|---|---|
| 第 1 行 | 7, 25, 43, 61, 79 | 7 |
| 第 2 行 | 7, 25, 43, 61, 79 | 25 |
| 第 3 行 | 7, **34**, 61（空格）+ 79（语音） | 43 |

**网格线是 7/25/43/61/79，第 3 行的 34 是唯一离格值。**
