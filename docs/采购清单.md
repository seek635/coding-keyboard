# ClaudePad 采购清单（BOM）

**版本**：v0.1（原型阶段）
**日期**：2026-09-14
**方案**：现成套件改造 + 定制 PCB
**键盘规格**：三行五列 15 格 · 11 键（含回车跨2格 / 空格跨4格）· 侧边审批拨杆 · BLE 无线

> ⚠️ **价格说明**：本清单**不标注具体价格**，因为电子元件价格波动大且随渠道差异明显。请以淘宝/立创商城实时报价为准。清单中给出的是**规格要求**和**选型理由**，照着规格买不会错。

---

## 一、核心结论（先看这个）

### 1.1 为什么不能直接买「套件」

市面上**没有**符合本项目布局的现成套件。你的键盘有两个特殊点：

1. **非标准布局**——三行五列，空格跨 4 格、回车跨 2 格，没有套件是这个形状
2. **侧边审批拨杆**——这是自定义部件，任何套件都不会有

**因此实际做法是：**

> **买一套标准套件 → 用它练手 + 拿它的主控/轴体/键帽/线材 → 然后自己画 PCB 或洞洞板搭真正的 ClaudePad**

套件的价值在于：**验证 BLE 连接和 ZMK 固件能力**，以及**提供一套不会被浪费的通用零件**（主控、轴体、键帽通用）。

### 1.2 强烈建议的推进顺序

| 步骤 | 买什么 | 目的 |
|---|---|---|
| **第 1 步** | 只买「最小验证集」（见第三章） | 花最少的钱验证：BLE 能否连上、ZMK 能否自定义按键、拨杆能否被识别 |
| **第 2 步** | 验证通过后，买完整元器件做原型 | 做真正的三行五列键盘 |
| **第 3 步** | 原型好用后，打定制 PCB | 做正式版 |

**不要一上来就买全套**——你的布局和拨杆机制都还没验证，先花小钱试通再投入。

## 二、轴体选型建议（你让我推荐）

### 2.1 推荐：凯华 Choc 矮轴（Kailh Choc V2）

**推荐理由：**

| 维度 | Choc 矮轴 | 标准 MX 轴 |
|---|---|---|
| 总高度 | **低（含键帽约 11mm）** | 高（含键帽约 18mm） |
| 键程 | 短（3.0mm 左右） | 长（4.0mm） |
| 触发力度 | 轻（红轴约 35-50g） | 标准（红轴约 45g） |
| 适合场景 | **高频敲击、快速触发** | 长时间打字 |
| 键盘厚度 | 可做很薄 | 偏厚 |

**为什么给你推荐矮轴**：ClaudePad 是**快捷键键盘**，不是打字键盘。使用特征是「快速点按」而非「长时间连续输入」。矮轴的短键程意味着：

- **触发更快**——按下去 1.5mm 就触发，比 MX 轴少走一半路程
- **回弹更快**——连续按方向键时更跟手
- **键盘更薄**——放桌面不占高度，也不用配掌托

### 2.2 具体轴体推荐（按手感排序）

| 轴体 | 手感 | 推荐场景 |
|---|---|---|
| **Choc 红轴（Linear）** | 直上直下，无明显段落 | **首选**。快捷键键盘不需要段落反馈，线性轴触发最干脆 |
| **Choc 茶轴（Tactile）** | 有轻微段落感 | 如果你喜欢"按下去有确认感" |
| **Choc 白轴（Click）** | 有明显咔哒声 | 不建议——办公室会吵到人 |

**力度建议**：选 **轻力度版本**（35-40g）。快捷键键盘需要高频快速点按，轻力度能显著降低手指疲劳。

### 2.3 键帽配套（★ 已改为自己 3D 打印）

**结论：键帽不用买，直接用项目里的 CAD 模型打印。**

原因：本项目是**三行五列非标布局**，空格跨 4 格、回车跨 2 格，市面上的 Choc 键帽套装根本不匹配。而且 Choc 生态的**大键（2u 以上）键帽极其难买**。

所以项目已产出可打印的键帽模型（`cad/keycap.scad`）：

| 键帽 | 文件 | 数量 | 打印耗时 |
|---|---|---|---|
| 1u 标准 | `03_keycap_1u.stl` | **9 个** | 约 12 min/个 |
| 2u 回车 | `04_keycap_2u.stl` | **1 个** | 约 20 min |
| 4u 空格 | `05_keycap_4u.stl` | **1 个** | 约 35 min |

键帽内部已做 **3 条加强筋**（4u）和 **3 个榫头**（对应空格下方的 3 个轴），解决长键翘曲问题。

> 如果你想买现成的：1u 键帽可以买（Choc 专用，**不能**用 MX 键帽），但 2u/4u 基本买不到，还是得打印。

### 2.4 大键的机械问题（重要）

空格跨 4 格 = 约 70mm 宽。**这么长的键按两端会翘，中间没支撑**。解决方案：

| 方案 | 说明 | 推荐度 |
|---|---|---|
| **多点支撑** | 在空格下方放 **3 个轴体**（左中右各一），三个轴并联到同一个开关电路 | ⭐⭐⭐⭐⭐ **推荐** |
| 卫星轴 / 平衡杆 | 传统大键方案，但 Choc 矮轴配套的卫星轴难找 | ⭐⭐ |
| 单轴 + 长键帽 | 按两端会翘，手感差 | ❌ 不推荐 |

**采购要点**：空格位置按 **3 个轴体**买（多备 2 个），PCB 上对应位置要留 3 个轴的焊盘。

## 六、采购注意事项（避坑）

### 6.1 主控相关

| 坑 | 说明 |
|---|---|
| **主控是否带充电管理** | nice!nano 自带，但一些廉价替代板**不带**，需另配 TP4056 充电模块 |
| **引脚定义是否兼容** | 买"Pro Micro 引脚兼容"版本，否则 ZMK 配置要用别人写好的板子定义 |
| **是否已烧 bootloader** | 买标注"已烧录 bootloader"的，否则要先烧 bootloader 才能用 |
| **芯片年份** | ⚠️ 市面 nice!nano 多为 **2020 年产芯片，容易坏**（EPPad 作者也提到）。尽量买正品 |

> **⚠️ 主控选型尚未定稿**：nice!nano（17.8 × 33mm）在 86×50 的板面上**放不下**，
> 需要移到 PCB 背面，或改用更小的模块（如 E73-2G4M08S1E，约 13×18mm）。
> 详见 `docs/PCB设计规格书.md` §14。
>
> **但第 1 批采购不受影响** —— nice!nano 是 ZMK 的参考平台，用来做 BLE 验证最省事，
> 即使最终改用 E73 也不会浪费（可继续用于测试）。

### 6.2 电池相关

| 坑 | 说明 |
|---|---|
| **插头规格** | JST 1.25 是主流，但有些是 JST 2.0，**买前确认主控的插座规格** |
| **尺寸** | 一定要**量好键盘内部空间**再买，电池买大了装不进去 |
| **保护板** | 买**带保护板**的电池，防过充过放 |

### 6.3 拨动开关相关

| 坑 | 说明 |
|---|---|
| **SPDT vs 自复位** | 必须买**SPDT 拨动开关**（拨过去停住），**不是**自复位按钮（松开回弹） |
| **轴套长度** | **必须 ≥ 9mm**。外壳壁 2.4 + 凸台 4.1 + 螺母 2.0 = 8.5mm，还要留余量。买短了装不上 |
| **轴套直径** | 默认按 φ6.0 建模（M6 螺纹），买前量一下，不对就改 `params.scad` 的 `SW_BUSH_D` |
| **引脚数** | 三脚（COM/NO/NC）最灵活 |

> 买回来先量三个尺寸：**轴套直径 / 轴套长度 / 面板尺寸**，对不上就改 `cad/lib/params.scad` 里对应的 `SW_*` 参数，然后跑 `python tools/check_dims.py` 复验（脚本会检查轴套能否穿过壁+凸台+螺母）。

### 6.4 轴体相关

| 坑 | 说明 |
|---|---|
| **Choc 版本** | Kailh Choc **V1 和 V2 引脚不同**，买前确认 |
| **键帽兼容** | Choc 键帽**不能**用在 MX 轴上，反之亦然，别买错 |
| **大键键帽** | ~~极难买~~ → **已解决**：本项目提供可打印的 2u/4u 键帽模型，见 2.3 |

### 6.5 USB 线相关

**必须是数据线**。市面上大量线材是"纯充电线"（只有电源针脚，没有数据针脚），插上去电脑不认设备，刷不了固件。买时确认标注"数据线"或"支持传输"。

## 十、本清单的边界说明

**本清单不包含：**

- ❌ **上位机软件部分**——审批拨杆要配合的桌面程序（读取终端输出/写 hooks）是**软件工作**，不需要采购
- ❌ **具体价格**——请以实时报价为准
- ❌ **具体购买链接**——型号规格已给全，按规格搜索即可；链接易失效，不如给规格

**本清单的假设：**

- 你有基本的焊接能力（或愿意学）
- 你能接触 3D 打印（自己打印或找代打）
- 你的电脑支持蓝牙（BLE 4.0 以上，现在电脑基本都支持）

## 十一、想跳过验证、直接开干？

**可以。** 但要知道代价，以及有一件事绕不过去。

### 11.1 跳过的代价

| 跳过什么 | 代价 |
|---|---|
| 面包板验证 BLE / ZMK / 拨杆 | 如果哪里不通，会在**焊完之后**才发现，拆起来麻烦 |
| 校准试件 | ⚠️ **不建议跳过** —— 见 11.2 |

**如果决定跳过**，那就一次买齐下面这份。

### 11.2 ★ 唯一不建议跳过的事：校准试件

`SWITCH_PLATE_GAP`（PCB 上表面 → 定位板下表面）是**唯一无法从公开资料确定的尺寸**。
Choc 官方没公开，社区实测在 3.5–6.0mm 浮动。

**它错 0.5mm 会怎样**：

- 定位板位置错 → 轴体卡扣扣不上定位板 → 定位板固定不住
- 而外壳内腔高度 = `PCB_STANDOFF_H + PCB_T + SWITCH_PLATE_GAP`
  → 这个值错了，**整个外壳（3–4 小时打印）要重打**

**两个解法，任选其一，都很快**：

| 方法 | 耗时 | 说明 |
|---|---|---|
| **A. 打校准试件** | 15 分钟打印 | `cad/output/00_test_coupon.stl`，3 个测试位，轴体插进去找「卡扣清脆」那个 |
| **B. 卡尺量实物** | 5 分钟 | 拿到轴体后，把轴体压平在桌面上，量「轴体底面 → 卡扣下沿」的距离 |

> **建议**：下单当天就把校准试件丢去打印（或找代打），和等快递**并行**，不占额外时间。
