# ClaudePad 新手采购清单

**面向**：第一次做硬件、要手工焊接的人
**前提**：外壳 / 定位板 / 键帽**已经 3D 打印完成**，这里只列要买的电子件
**原则**：只列项目必需的，不加多余配件；优先推荐**好焊、容错高**的型号

---

## ⚠️ 买之前先看这两条

这两条不影响你买什么，但影响**你打印的外壳能不能用**，先确认一下。

### 1. 主控已改到 PCB 背面 ✅（2026-09-16 解决）

原本主控在 PCB 正面，与 4 个轴体重叠 322.52 mm²（板面 86×50 被 14 个轴体占满，放不下）。
现已改为**装在 PCB 背面右侧**，26 项结构校验全部通过。

**但有两件事要先告诉你：**

**① 你已打印的外壳需要重做**

支撑台位置（在底板上）和 USB 开孔高度（在右壁上）都变了。
**顶盖和定位板不受影响**，重打这两件即可。

**② USB 口够不到外壳右壁 ✅ 已解决**

原本 USB 口距内腔右壁 8.2mm，而插头金属部分只有 6.5mm，插不到底。
已通过 **PCB 加宽**（86 → 98mm）解决：现在距离 2.15mm，插入深度 4.55mm。
**不需要额外买延长线。**

**③ 轴体改用 Choc V2 —— 键帽要重打**

V2（PG1353）的轴心是 **MX 十字**，V1（PG1350）是矩形小十字，**两者键帽互不通用**。
你已打印的键帽是按 V1 做的，插不进 V2。需要用 `cad/output/03~05_*.stl` 重新打印
（模型已按 MX 十字更新）。**定位板不用换**，外壳也不用（内腔尺寸没变）。

→ 详情见 `docs/PCB设计规格书.md` §14.5（实施记录）与 §14.6（USB 遗留问题）。

### 2. 轴体卡扣间隙（`SWITCH_PLATE_GAP`）没实测过

这个值决定「定位板装在外壳里的高度」，当前取 5.0mm，但真实值可能是 3.5–6.0mm 之间。
如果和实际不符，**定位板会装不到位，外壳内腔高度也得改**。

**怎么验证**（两选一，都很快）：
- 拿到轴体后，用卡尺量「轴体底面 → 卡扣下沿」
- 或者打印 `cad/output/00_test_coupon.stl`，把轴体插进去试哪个卡扣最清脆

### 3. 二极管 ★ 新手最容易买错的一项

| | |
|---|---|
| **名称** | **1N4148 直插二极管（DO-35 玻璃封装）** |
| **数量** | **12 个** |
| **用途** | 键盘矩阵防「鬼影」——同时按多个键时不误判 |
| **规格** | **直插**，引脚长，玻璃封装 |

**★ 一定要买「直插」，不要买贴片！**

| | 直插 DO-35（选它） | 贴片 0805（别买） |
|---|---|---|
| 大小 | 约 4mm 长，引脚伸出 25mm | 2mm × 1.25mm，**肉眼难辨** |
| 焊接 | 手捏着引脚就能焊 | 要镊子 + 放大镜 |
| 新手成功率 | 高 | 低 |

**方向不能接反**：**阳极（有黑环的反面）接列线，阴极（黑环那端）接行线**。
接反了不会烧，但按键读不出来，排查很痛苦——**焊之前先在纸上画一遍**。

**为什么是 12 个而不是 14 个**：二极管是「每个矩阵位置一个」，空格 3 个轴并联成 1 个位置、回车 2 个轴并联成 1 个位置，所以 14 个轴只对应 12 个位置。

### 5. 锂电池

| | |
|---|---|
| **名称** | **3.7V 锂聚合物电池** |
| **数量** | 1 块 |
| **用途** | 供电 |
| **规格** | **容量 ≥ 400mAh**（★ 见下方警告）/ **厚度 ≤4.0mm** / 带保护板 |

**★ 容量不能低于 400mAh —— 这是安全要求，不是建议**

你买的主控（nice!nano v2.0_SMT）说明书原文：

> 默认充电电流 **185mA**。**警告！充电电流必须小于等于电池容量的一半**，
> 否则电池寿命会加速衰减，**甚至会爆炸**。

185 ÷ 2 = **370mAh**，所以容量必须 ≥ 370mAh，取 **400mAh 以上**留余量。

| 电池容量 | 185mA 充电电流下 | 判定 |
|---|---|---|
| 300mAh | 300/2 = 150 < 185 | ❌ **超标，别买** |
| **400mAh** | 400/2 = 200 > 185 | ✅ 可以 |
| 500mAh | 250 > 185 | ✅ 更好 |

**另外两点**
- 主控的电池接口是 **B+ / B− 两个焊盘**（不是插座），所以电池买**带线**的即可，
  剪掉插头焊上去；不带插头的也行
- 厚度仍要 **≤ 4.0mm**（这一层总共只有 5.0mm）

**新手提示**
- ⚠️ **买带引线的，不要自己焊电池本体** —— 锂电池焊接有起火风险
- 主控的电池接口是 **B+ / B− 焊盘**（不是插座），所以：买**已经焊好引线**的电池，
  把引线焊到主控焊盘上即可。**不要买只有裸极耳的电池**
- ⚠️ **容量必须 ≥400mAh**（见上方警告，充电电流 185mA 的硬要求）
- ⚠️ **厚度必须 ≤4.0mm**，厚了装不进外壳（PCB 下方只有 5.0mm）
- 买带保护板的，防过充过放

### 14. 自复位轻触开关 ★ 用来进刷机模式

| | |
|---|---|
| **名称** | **6×6mm 轻触开关（长柄）** 或 **带引线的自复位小按钮** |
| **数量** | 1 个 |
| **用途** | 接在主控的 **RST** 和 **GND** 之间，按一下复位 —— 用来进刷机模式 |
| **规格** | 柄长 **≥8mm**（要穿过 2mm 底板）；或选**带引线**的款 |

**为什么必须买**

你买的这块主控（nice!nano v2.0_SMT）**没有复位按钮**。说明书写得很清楚：

> 如果想要进入 Bootloader，请在 **0.5S 内短接 2 次 RST 到 GND**

官方 nice!nano 有物理按钮（双击进入），**这块没有** —— 所以要自己补一个。

**怎么装**

外壳底板**已经预留了一个 φ8mm 的孔**（位置正好在主控外侧，不在主控正下方）：

1. 把轻触开关贴在**底板内侧**，柄对准 φ8mm 孔露出来
2. 两根引线分别焊到主控的 **RST** 和 **GND**
3. 用热熔胶固定开关

> ⚠️ 开关总高要 **< 5mm**（底板到 PCB 之间只有 5.0mm），所以别买高身按钮。

**一个可以省事的办法**

ZMK 支持  行为 —— 可以在键位表里加一个键，以后**按键就能进刷机模式**。

⚠️ 但**第一次刷固件时键盘还没有固件**，那个键还不存在 —— 所以物理按钮省不掉。

**预算**：几块钱。

## 四、焊接顺序（新手建议）

按这个顺序焊，出错最容易发现：

```
1. 先只焊 12 个二极管
   → 焊完用万用表逐个测：正反导通方向对不对

2. 再走矩阵线（3 行 + 6 列）
   → 每走完一条线，测一次通断

3. 焊 14 个轴体
   → 大键的多个轴要并联到同一条线上

4. 最后接主控、拨杆、电池
   → 主控最后接，避免前面焊错把它烧了

5. 先插 USB 刷固件测试，确认按键都对了，再接电池
   → 这一步能省一块电池和一次返工
```

**两条通用原则**
- **每焊完一部分就测一次**，不要全部焊完再排查
- **烙铁停留时间控制在 2–3 秒**，太久会烫坏轴体塑料或焊盘脱落

## 六、主控怎么接线（新手常问）

### 要不要焊排针？

**不要。** 主控现在装在 PCB **背面**，而这一层的净空只有 **5.0mm**：

| 方案 | 占用高度 | 结果 |
|---|---|---|
| 主控本体 | 3.20mm | ✅ 剩 1.80mm |
| 再加标准排针座 | +2.54 = 5.74mm | ❌ 超过 5.0 |
| **导线直接焊** | 不额外占高度 | ✅ **采用** |

### 主控怎么固定、怎么连？

主控**贴在 PCB 背面**（紧贴），引脚**朝上穿过 PCB 上的孔**，焊在**正面**（轴体那一面）。

```
   轴体 ─────────────────────  PCB 正面（焊接面）
                              PCB 板
   主控 ▓▓▓▓▓▓▓▓▓▓▓  ←────  PCB 背面（主控贴这里）
        └─ 引脚向上穿过 PCB，焊在正面
```

**为什么这样最好**：主控紧贴 PCB，**不额外占高度**（总共只 3.2mm），
而那一层只有 5.0mm 可用。

nice!nano 边缘是 **2.54mm 通孔**，洞洞板也是 2.54mm 网格 —— **能对齐**。

### nano 怎么摆？

- **元件面朝下**（有蓝色 LED 和复位按钮的那一面，朝向底板）
  - 这样 **USB-C 口在下方**，正好对准右壁那个开孔
  - ⚠️ 这块板**没有复位按钮**，进刷机模式要短接 RST 到 GND → 需要另装一个按钮（见第 14 项）
- **USB-C 口朝右壁**
- 位置固定：**PCB 坐标 (68.0, 8.5)**，贴着 PCB 右侧（右边距仅 0.2mm）

> ⚠️ 元件面朝下意味着主控的**芯片和 USB 座都在下面**，与底板之间只剩 **1.80mm**。
> 装的时候别把导线压在主控底下。

### 数据线要买吗？

**要。** nice!nano **不带线**，而且必须是**数据线**不是纯充电线。
用途有两个：刷固件 + 给电池充电。
