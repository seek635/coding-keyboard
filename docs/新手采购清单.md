# ClaudePad 新手采购清单

**面向**：第一次做硬件、要手工焊接的人
**前提**：外壳 / 定位板 / 键帽**已经 3D 打印完成**，这里只列要买的电子件
**原则**：只列项目必需的，不加多余配件；优先推荐**好焊、容错高**的型号

---

## ⚠️ 买之前先看这两条

这两条不影响你买什么，但影响**你打印的外壳能不能用**，先确认一下。

### 1. 主控在板面上的位置有冲突（未解决）

当前设计里，主控与 4 个轴体的位置**重叠 322.52 mm²**，等于 2 个轴体被主控压住。
板面 86×50mm 被 14 个轴体占满，**没有任何位置放得下主控**。

→ 详情见 `docs/PCB设计规格书.md` §14。**这个问题定下来之前，外壳可能需要重打。**

### 2. 轴体卡扣间隙（`SWITCH_PLATE_GAP`）没实测过

这个值决定「定位板装在外壳里的高度」，当前取 5.0mm，但真实值可能是 3.5–6.0mm 之间。
如果和实际不符，**定位板会装不到位，外壳内腔高度也得改**。

**怎么验证**（两选一，都很快）：
- 拿到轴体后，用卡尺量「轴体底面 → 卡扣下沿」
- 或者打印 `cad/output/00_test_coupon.stl`，把轴体插进去试哪个卡扣最清脆

## 一、必需清单（13 项）

### 1. 主控板

| | |
|---|---|
| **名称** | **nice!nano v2** |
| **数量** | 1 块 |
| **用途** | 键盘的大脑。跑 ZMK 固件，把按键通过蓝牙发给电脑 |
| **规格** | nRF52840 芯片 / Pro Micro 引脚兼容 / 板载天线 / USB-C / 已烧 bootloader |

**新手提示**
- ⚠️ **认准正品**。市面很多是 2020 年产芯片，容易坏
- 买「Pro Micro 引脚兼容」版本，否则固件要改引脚定义

**它已经自带的（不用另买）**
- ✅ 锂电池充电电路
- ✅ 复位按钮（双击进刷机模式）
- ✅ Bootloader（可直接拖拽 .uf2 刷固件）
- ❌ **没有**物理电源开关 → 需要另买（见第 6 项）

### 2. 轴体

| | |
|---|---|
| **名称** | **凯华 Choc V1 矮轴 · 红轴（线性）** |
| **数量** | **14 个** |
| **用途** | 按键本体。空格用 3 个、回车用 2 个，其余每键 1 个 |
| **规格** | 轻力度 35–40g / 矮轴 / 键程 3.0mm |

**为什么选红轴**：直上直下没有段落感，触发最干脆，适合高频点按的快捷键键盘。

**新手提示**
- 每个轴只有 **2 个引脚**，插进去焊上就行，很好焊
- ⚠️ **Choc 是矮轴**，和普通 MX 轴**不通用**（键帽、定位板都不一样），别买错
- 建议多买 1–2 个备用（偶尔会碰到个别轴体手感异常的）

---

### 3. 二极管 ★ 新手最容易买错的一项

| | |
|---|---|
| **名称** | **1N4148 直插二极管（DO-35 玻璃封装）** |
| **数量** | **12 个** |
| **用途** | 键盘矩阵防「鬼影」——同时按多个键时不误判 |
| **规格** | **直插**，引脚长，玻璃封装 |

**★ 一定要买「直插」，不要买贴片！**

| | 直插 DO-35（选它） | 贴片 0805（别买） |
|---|---|---|
| 大小 | 约 4mm 长，引脚伸出 25mm | 2mm × 1.25mm，**肉眼难辨** |
| 焊接 | 手捏着引脚就能焊 | 要镊子 + 放大镜 |
| 新手成功率 | 高 | 低 |

**方向不能接反**：**阳极（有黑环的反面）接列线，阴极（黑环那端）接行线**。
接反了不会烧，但按键读不出来，排查很痛苦——**焊之前先在纸上画一遍**。

**为什么是 12 个而不是 14 个**：二极管是「每个矩阵位置一个」，空格 3 个轴并联成 1 个位置、回车 2 个轴并联成 1 个位置，所以 14 个轴只对应 12 个位置。

---

### 4. 拨动开关（审批拨杆）

| | |
|---|---|
| **名称** | **SPDT 三脚拨动开关** |
| **数量** | 1 个 |
| **用途** | 侧边的审批拨杆 |
| **规格** | **三脚（COM / NO / NC）** / **轴套长度 ≥ 9mm** / **带焊片的更好焊** |

**两个必须注意的**
- ⚠️ **要「拨过去停住」的，不是自复位按钮**（松开回弹的那种）——否则做不出 OFF/ON 两态
- ⚠️ **轴套长度必须 ≥9mm**：外壳壁 2.4 + 凸台 4.1 + 螺母 2.0 = 8.5mm，买短了装不上

**新手提示**：选**带焊片（接线片）**的型号，焊片面积大，比 PCB 插脚好焊得多。

## 三、不用买（会白花钱）

| 不要买 | 原因 |
|---|---|
| **复位按钮** | nice!nano **自带**（双击进刷机模式） |
| **充电模块 / TP4056** | nice!nano **自带**充电电路 |
| **键帽 / 定位板 / 外壳** | 你已经 3D 打印了 |
| **排针 / 排母** | 实测主控上方净空只有 **3.40mm**，标准排针凸出 ~8.5mm，**装不进去**。导线直接焊到 nano 的孔里（见下方说明） |
| **热插拔轴座** | 轴座在 PCB 下方凸出 2.5–3.0mm，而那一层只有 5.0mm、电池已占 4.6mm，**必然打架** |
| **成品 PCB** | 市面上没有符合这个布局的板（空格中间那根轴不在标准网格上） |
| **ESP32 / ESP32-WROOM-32** | 三个硬伤：开发板厚 **10mm**（键盘只有 3.4 / 5.0mm）；模组引脚间距 **1.27mm** 焊不进洞洞板；**跑不了 ZMK**，要自己写 C 代码。续航还只有 nRF52840 的 1/10 |

## 四、焊接顺序（新手建议）

按这个顺序焊，出错最容易发现：

```
1. 先只焊 12 个二极管
   → 焊完用万用表逐个测：正反导通方向对不对

2. 再走矩阵线（3 行 + 6 列）
   → 每走完一条线，测一次通断

3. 焊 14 个轴体
   → 大键的多个轴要并联到同一条线上

4. 最后接主控、拨杆、电池
   → 主控最后接，避免前面焊错把它烧了

5. 先插 USB 刷固件测试，确认按键都对了，再接电池
   → 这一步能省一块电池和一次返工
```

**两条通用原则**
- **每焊完一部分就测一次**，不要全部焊完再排查
- **烙铁停留时间控制在 2–3 秒**，太久会烫坏轴体塑料或焊盘脱落

## 六、主控怎么接线（新手常问）

### 要不要焊排针？

**不要。** 实测主控上方的净空只有 **3.40mm**：

| 方案 | 凸出高度 | 结果 |
|---|---|---|
| 标准排针 + 排母 | ~8.5mm | ❌ 装不下 |
| 超矮排针 | ~3.0mm | ⚠️ 勉强，只剩 0.4mm 余量，不建议 |
| **导线直接焊** | 0 | ✅ **采用** |

### 正确做法：导线直接焊进 nano 的孔里

nice!nano 边缘是一圈 **2.54mm 通孔**，所以：

1. 线头先**上锡**（剥皮 → 蘸助焊剂 → 烙铁烫一下让锡包住线头）
2. 把线上锡的那头**从孔里穿过去**
3. 烙铁一碰，两个锡就融在一起了

> 这比"焊在表面"容易得多——**孔是给新手准备的**。线穿过去之后不会乱跑，单手也能操作。

### nano 怎么摆？

- **元件面朝上**（有蓝色 LED 和复位按钮的那一面）—— 这样你能看到状态灯、能按到复位键
- **USB-C 口对准外壳侧壁的开孔**
- ⚠️ nano 在外壳里的**确切位置还没定**（主控与轴体重叠的问题未解决，见开头提醒）

### 数据线要买吗？

**要。** nice!nano **不带线**，而且必须是**数据线**不是纯充电线。
用途有两个：刷固件 + 给电池充电。
