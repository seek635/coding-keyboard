# ClaudePad 结构设计规格书

**版本**：v0.4
**日期**：2026-09-20
**制造方式**：FDM 3D 打印（0.4mm 喷嘴）
**配套文件**：`cad/*.scad`（参数化模型）· `tools/*.py`（校验与导出）

> **v0.4 同步**：把本文档对齐到 `params.scad` 的实际值。此前有三轮改动只改了模型没改文档：
> 主控移到 **PCB 背面**（§1.3 / §3）、PCB 加宽 86 → **98mm**、轴体改用 **Choc V2**

> 整机高度因此从 23.10 变为 **23.30mm**，PCB 尺寸从 86×50 变为 **98×50**。

> 整机高度 20.1 → 23.1mm。详见 §1.3 与 `docs/按键行程图.png`。
>
> **v0.2 修正**：内腔高度写死导致轴体够不到 PCB、定位板宽度算错 12mm。
>
> 现在垂直方向的尺寸**全部由零件堆叠推导**，不再有写死的数值。

## 1. 总体尺寸

### 1.1 整机外形

| 项目 | 尺寸 |
|---|---|
| **长（X，列方向）** | **107.10 mm** |
| **宽（Y，行方向）** | **71.10 mm** |
| **高（Z，桌面到键帽顶）** | **23.30 mm** |
| 底座本体高 | 14.80 mm |
| 重量（预估） | 约 140–170 g |

**作为参照**：标准 104 键键盘宽约 440mm，ClaudePad 只有它的 1/4。

### 1.2 垂直尺寸链（关键）

```
z = 23.30  ┌─────────────────┐  键帽顶面
           │    键帽 5.0     │
z = 18.30  ├─────────────────┤  键帽底面（离定位板 3.5）
           │  行程空间 3.5    │  ★ 必须 ≥ 轴体键程 3.2
z = 14.80  ├═════════════════┤  定位板上表面
           │   定位板 1.2    │
z = 13.60  ├─────────────────┤  定位板下表面 ◄─ 轴体卡扣在此
           │  轴体卡扣 5.0    │  ★ 待实物确认
z =  8.60  ├─────────────────┤  PCB 上表面（轴体焊接面）
           │     PCB 1.6     │
z =  7.00  ├─────────────────┤  PCB 下表面
           │ 主控/电池 5.0    │  ← 主控 3.2（贴板背面）+ 电池 4.0 + 胶 0.6
z =  2.00  ├─────────────────┤  底板上表面
           │    底板 2.0     │
z =  0.00  └─────────────────┘  桌面（含 0.2 倒角）
```

**内腔净高 = 5.0（电池/走线）+ 1.6（PCB）+ 5.0（轴体卡扣）= 11.6mm**

> ⚠️ 这个 11.6 是**算出来的**，不是拍的。改任何一个零件尺寸，它自动跟着变。
> 改参数后跑 `python tools/check_dims.py`，会校验整条链是否还自洽。

### 1.3 两个必须知道的耦合关系

**耦合 1：PCB 下方层高同时决定电池与主控**

主控**装在 PCB 背面**（v0.4 起），与电池共用 PCB 下方这 5.0mm。两者平面**不重叠**
（电池贴内腔左壁、主控贴右侧），但层高必须同时容下最厚的那个：

| 占用 | 高度 |
|---|---|
| 电池 4.0 + 双面泡棉胶 0.6 | **4.6 mm** ← 决定层高 |
| 主控 3.2（贴 PCB 背面，元件面朝下） | 3.2 mm（余 1.8） |

所以 `PCB_STANDOFF_H = 5.0` 是**电池**定的，不是主控。想改薄键盘，先确认电池装得下。

> **v0.4 之前**：主控装在 PCB **正面**，与轴体争板面 —— 14 个轴体几乎占满板面，
> 穷举后「零重叠位置数 = 0」。移到背面后这条约束消失，`SWITCH_PLATE_GAP`
> 不再兼任「主控净空」，只由**轴体卡扣位置**决定。详见 `docs/PCB设计规格书.md` §14。

**耦合 2：键帽间隙必须 ≥ 轴体键程**（v0.3 修正的 bug）

键帽裙边 **17.6mm** 比定位板轴孔 **13.8mm** 宽，**塞不进孔里**。所以键帽只能整体悬在定位板上方，
下压时裙边会直接撞到板面。

```
键帽底面离定位板 ≥ 轴体键程
CAP_GAP (3.5) ≥ SWITCH_TRAVEL (3.2)   ✅
```

> **v0.1–v0.2 的 `CAP_GAP = 0.3mm` 是错的** —— 按键只能按下 0.3mm 就顶死，剩余行程全废，
> **按键根本按不动**。修正后整机从 20.1mm 变成 23.1mm，这 3mm 是物理上必须的。
> v0.4 换 Choc V2 后键程 3.0 → 3.2，整机再涨到 23.3mm。
> 详见 `docs/按键行程图.png`。

## 3. 内部布局

### 3.1 俯视分区

下图是**去掉定位板后**的俯视示意（主控和电池都在 PCB **下表面**那一层，左右分开）：

```
        ┌───────────────────────────────────────────────┐
        │ [柱]                              [柱]        │
        │                                               │
        │  ┌────────────┐            ┌──────────────┐   │
        │  │            │            │  NoLogo      │   │
        │  │  电池仓     │            │  主控        │───┼─→ USB-C 开孔
        │  │  30 × 40   │            │  17.78 × 33  │   │    （右壁）
        │  │  （贴左壁）  │            │  （贴右壁）   │   │
        │  └────────────┘            └──────────────┘   │
        │ [柱]                              [柱]        │
        │                                               │
        │  ←─── 走线通道 A（沿下缘）────→                 │
        └───────────────────────────────────────────────┘
          右壁外侧：审批拨杆凸台（外凸 4.1mm）
```

> **为什么左右分开**：两者同处 PCB 下方这一层（只有 5.0mm）。电池 40mm 长、主控 33mm 长，
> 内腔宽度装不下并排两个，所以电池贴左壁、主控贴右壁，靠 X 方向错开。
> 支撑台因此只能取 x = 40 / 76 这两个轴体间隙中心（x = 22 被电池占、x = 94 不存在）。

### 3.2 各部件安装位置与固定方式

| 部件 | 位置 | 固定方式 | 可拆 |
|---|---|---|---|
| **定位板** | 内腔顶部，与外壳上沿**齐平** | 4 颗 M2×6 螺丝，穿过定位板拧入四角螺丝柱 | ✅ |
| **PCB** | 内腔中部，托在 4 个矮支撑台上 | 靠轴体 + 定位板压住（不需螺丝） | ✅ |
| **NoLogo ProMicro 主控** | **PCB 背面（下表面）右侧** | **必须直接焊在 PCB 上**（不能用普通排母，高度不够） | ❌ |
| **锂电池** | **PCB 正下方，贴内腔左壁** | 双面泡棉胶贴底 + 限位挡墙 | ✅ |
| **SPDT 拨杆** | 右壁外侧凸台 | 轴套穿过 φ6.2 孔，**外侧**拧螺母锁紧（拨杆+轴套+螺母在壳外，开关本体在壳内） | ✅ |
| **脚垫 × 4** | 底面四角沉孔 | 硅胶脚垫压入 | — |

### 3.3 为什么这样分区

| 决策 | 理由 |
|---|---|
| **电池走 PCB 正下方** | 内腔平面只有 102×66，电池 30×40 无法与 PCB（98×50）并排放置；且电池放最下层，远离主控发热 |
| **主控靠右** | USB-C 开孔开在右壁上，主控越靠右开孔越浅越好做 |
| **主控必须直焊** | 这层只有 5.0mm 高，普通排母（8.5mm）根本放不下。这是"薄"换来的代价 |
| **拨杆在右壁** | 拇指自然落点；信号线沿右壁竖直走，路径最短 |
| **定位板与上沿齐平** | 视觉整洁，且定位板被内腔四壁框住，不会横向晃动 |

## 4. 走线通道

### 4.1 两条主干道

| 通道 | 路径 | 走什么线 |
|---|---|---|
| **A** | 沿下缘横向 | 键位矩阵行线（3 条）+ 列线（5 条） |
| **B** | 沿右缘纵向 | 拨杆信号线（2 条）+ 地线 |

规格：槽宽 3.0 × 深 2.0mm，从底板上表面下挖。

### 4.2 走线规则

1. **所有飞线走 PCB 下方**（PCB 抬高 5.0mm 的这层），PCB 上方只允许轴体引脚和主控。
2. 走线槽转角做圆角，防割线皮。
3. 线径上限 2.2mm（30AWG 硅胶线约 0.8mm，余量充裕）。
4. 每根线两端留 5–8mm 余量，方便拆装。

## 5. 散热与间隙

### 5.1 发热源

| 部件 | 发热 | 处理 |
|---|---|---|
| NoLogo ProMicro（nRF52840） | 中（BLE 脉冲） | 正下方（底板上）开 6 个 φ4 通气孔形成对流 |
| 充电 IC | 中（充电时） | 同上 |
| 电池 | 不发热但**怕热** | 与主控同在 PCB 下方这一层，但**平面错开到两侧**，互不叠加 |

### 5.2 间隙要求

| 位置 | 最小间隙 |
|---|---|
| 元器件 ↔ 元器件 | 0.5 mm |
| 主控 ↔ 底板 | 0.3 mm（当前实际 **1.8mm**，主控 3.2 贴 PCB 背面，下方余 1.8） |
| 走线槽 ↔ 元器件 | 1.0 mm |
| 电池 ↔ PCB | 由 PCB_STANDOFF_H 保证（胶 0.6 + 电池 4.0 = 4.6 ≤ 5.0） |

### 5.3 通气孔

**3×2 共 6 个 φ4 孔**，开在底板上、跟随主控位置（因此随主控一起移到了右侧）。
作用：主控与充电 IC 的散热对流。

> v0.4 之前主控在 PCB 正面，通气孔在电池上方，兼有「电池鼓包泄压」的作用；
> 现在电池已让位到左壁、通气孔跟着主控到了右侧，**泄压作用不再成立**。

## 6. 公差总表（3D 打印直接照用）

FDM 打印的孔会比设计值小，所以孔一律放大。

| 部位 | 设计值 | 打印应设 | 说明 |
|---|---|---|---|
| **轴体开孔** | 13.80 | **13.90 ~ 13.95** | **最关键**。过紧装不进，过松轴体晃 |
| M2 自攻底孔 | 1.70 | **1.70** | PLA 可直接拧自攻螺丝 |
| M2 通孔 | 2.00 | **2.30** | 定位板过孔 |
| 拨杆轴套孔 | 6.00 | **6.20** | 要螺纹咬合，宁紧勿松 |
| 拨杆运动槽 | 4.50 | **4.70** | 要能自由拨动 |
| USB-C 开孔 | 9.0×3.6 | **9.4×4.4** | **宁大勿小** |
| 定位板 ↔ 内腔 | — | 单边 **+0.15** | 落入式配合 |
| 电池仓 | — | 单边 **+1.00** | 电池实物误差大 |
| 键帽外宽 | 17.60 | **17.60** | = 间距 − 0.4，防相邻摩擦 |
| 键帽榫槽宽 | 1.30 | **1.30** | **MX 十字**筋厚 ~1.2，留 0.1 松配（V1 小十字是 0.95） |
| 键帽十字臂长 | 4.00 | **4.00** | MX 标准（V1 小十字只有 1.20） |
| 底部倒角 | — | **0.2×45°** | 防首层大象脚卡死 |

**孔轴线平行热床**（孔径最准），所有零件**不需要支撑**。

### 6.1 CSG 融合重叠（建模规则，不是打印公差）

所有「贴附在母体表面」的凸起（螺丝柱 / PCB 支撑台 / 电池挡墙 / 拨杆凸台）在建模时都**往母体里多伸 0.5mm**（`FUSE_OVERLAP`）。

**为什么**：如果两个实体的面完全共面，布尔并集后会产生**非流形边** —— STL 不水密，切片软件可能报错或产生薄壁。

这个问题是在**真实渲染验证**中发现的：第一版底座 STL 有 64 / 11300 条边不是恰好被 2 个面共用。加上 0.5mm 重叠后完全水密。

> 校验方法：`python tools/verify_stl.py` —— 它会检查每个 STL 的水密性与包围盒尺寸。

### 6.2 已通过的真实渲染验证

6 个零件全部导出 STL 并校验通过：

| 零件 | 实测包围盒 | 偏差 |
|---|---|---|
| 底座 | 111.20 × 71.10 × 14.60 mm | 0.00 |
| 定位板 | 102.00 × 66.00 × 1.20 mm | 0.00 |
| 键帽 1u | 17.60 × 17.60 × 5.00 mm | 0.00 |
| 键帽 2u | 35.60 × 17.60 × 5.00 mm | 0.00 |
| 键帽 4u | 71.60 × 17.60 × 5.00 mm | 0.00 |

> 底座 X 含壳外拨杆凸台（+4.10mm），Z 少底部防大象脚倒角（−0.20mm），均为设计值。

## 8. 装配顺序

```
第 1 步  主控焊到 PCB
        └─ NoLogo ProMicro 直接焊在 PCB **背面**（不用排母！高度不够）
        └─ 引脚朝上穿过 PCB，焊在正面
        └─ 焊二极管（矩阵防鬼影）

第 2 步  定位板装轴体
        └─ 从定位板正面按入 11 个轴
        └─ 空格位装 3 个轴（左中右），回车位装 2 个
        └─ ⚠️ 装前先试插 1 个，确认松紧

第 3 步  焊接
        └─ 定位板 + 轴体翻转，对齐 PCB 引脚，逐个焊
        └─ 焊拨杆引线（留 8mm 余量）
        └─ 🔌 先接 USB 测一遍：所有键是否响应、拨杆是否识别
        └─ ⚠️ 这一步别跳过，焊完再拆开查线最痛苦

第 4 步  装进底座
        └─ 定位板+PCB 组合体放入内腔，对准四角螺丝柱
        └─ 4 颗 M2×6 螺丝**对角交替**拧紧（别一次拧死）

第 5 步  电池
        └─ 电池背面贴双面泡棉胶
        └─ 塞入 PCB 下方**左侧**（主控在右侧，两边不叠；注意极性）
        └─ 走线沿通道 A 归拢

第 6 步  拨杆
        └─ SPDT 开关本体从右壁**内侧**对准轴套孔，轴套穿出壳外
        └─ **壳外**套垫片、拧螺母锁紧（螺母在凸台外侧，见 §11.2）
        └─ 拨动几次确认行程顺畅

第 7 步  收尾
        └─ 底面贴 4 个硅胶脚垫
        └─ 上键帽（注意 2u/4u 位置别装错）
        └─ 🎉 通电
```

## 9. 分步打印路线（强烈建议照做）

| 顺序 | 打什么 | 验证什么 | 耗时 |
|---|---|---|---|
| **①** | `00_test_coupon.stl` | **轴体卡扣间隙**（最关键） | 15 min |
| ② | `02_plate.stl` | 轴孔松紧、键帽能否挂住 | 40 min |
| ③ | `05_keycap_4u.stl` | 三轴支撑手感 | 35 min |
| ④ | `01_case_bottom.stl` | 孔位与装配 | 3–4 h |
| ⑤ | 全部 | — | — |

### 第 ① 步怎么用（最重要）

校准试件上有 **3 个测试位**，卡扣间隙分别是 **3.50 / 4.25 / 5.00mm**：

1. 拿一个**真实 Choc 轴体**，逐个插进去
2. 找那个「卡扣清脆扣入，且轴体塑料底面刚好贴住基座顶面」的位置
3. **判读**：
   - 轴体底面与基座之间有缝隙 → 该位间隙**偏大**
   - 卡扣扣不上，或扣上后底面顶住基座 → 该位间隙**偏小**
   - 完全贴合 + 卡扣清脆 → ✅ **就是它**
4. 把 `cad/lib/params.scad` 里的 `SWITCH_PLATE_GAP` 改成该值
5. 重跑校验和导出：
   ```bash
   python tools/check_dims.py
   python tools/export_stl.py
   ```

**为什么必须先做这步**：`SWITCH_PLATE_GAP` 是整套模型里**唯一无法从公开资料确定**的尺寸。Choc 官方未公开定位板高度，社区实测在 3.5–6.0mm 之间浮动。花 15 分钟测准，比打完 4 小时外壳才发现按不动划算得多。

**如果三个测试位都不合适**：改 `test_coupon.scad` 里的 `GAPS` 数组，重打一次（15 分钟）。

| M2 × 6mm 自攻螺丝 | 十字盘头 | 4 | 固定定位板 |
| 硅胶脚垫 | φ8mm，背胶 | 4 | 底面防滑 |
| 双面泡棉胶 | 0.6mm 厚 | 1 片 | 固定电池 |
| SPDT 拨动开关 | 轴套 φ6、长 **≥9mm** | 1 | 审批拨杆 |

> 螺丝多备 1.5 倍，极易丢。

## 11. 常见问题与对策

### 11.1 打印类

| 问题 | 对策 |
|---|---|
| 轴孔装不进 | `params.scad` 里 `SWITCH_CUTOUT_TOL` 从 0.10 调到 0.20 |
| 轴体装进去晃 | 调到 0.05 |
| 键帽榫槽太紧 | `CAP_STEM_GAP` 调到 1.05 |
| 键帽榫槽太松 | 调到 0.90 |
| 底部装不进底座 | 确认底部 0.2×45° 倒角已生效 |
| 定位板卡在内腔里 | 调大 `CASE_TOP_TOL`，或砂纸修定位板四边 |
| 空格按两端翘 | 确认空格装了 3 个轴（不是 1 个） |

### 11.2 拨杆选型注意

**必须买 SPDT 拨动开关**（拨过去停住的），不是自复位按钮。

**安装方向**：拨杆 + 轴套 + 螺母在**壳外**，开关本体在**壳内**。所以壳壁上只需要一个轴套过孔，**不需要拨杆行程槽**（拨杆在壳外摆动，不干涉壳体）。

默认按这个规格建模：

| 参数 | 值 | 参数名 |
|---|---|---|
| 轴套直径 | 6.0 mm | `SW_BUSH_D` |
| 轴套长度 | **≥ 9.0 mm** | `SW_BUSH_H` |
| 螺母厚度 | 2.0 mm | `SW_NUT_T` |
| 凸台直径 | 12.0 mm | `SW_BOSS_D` |

**为什么轴套要 ≥9mm**：外壳壁 2.4mm + 凸台 4.1mm + 螺母 2.0mm = 8.5mm，还要留 0.5mm 余量。

**买回来先量**，对不上就改 `params.scad` 里对应的 `SW_*` 参数，然后重跑校验 —— `check_dims.py` 会检查：
- 轴套能否穿过 壁+凸台+螺母
- 凸台会不会穿出外壳上下表面
- PCB 缺口够不够让开开关本体

### 11.3 电池选型注意

PCB 下方净高 5.0mm，减去泡棉胶 0.6mm，**电池厚度上限 4.4mm**。

| 规格 | 是否合适 |
|---|---|
| 3.7V 400–500mAh，厚 ≤4.0mm，**带引线**（焊到主控 B+ / B− 焊盘） | ✅ 推荐 |
| 3.7V 500mAh，厚 5.0mm | ❌ 需改 `PCB_STANDOFF_H` 到 6.0（整机变厚 1mm） |
| 3.7V 1000mAh 以上 | ❌ 装不下 |

**务必带保护板**。买前量实际长宽厚，电池是「标称和实物差最多」的元件。

## 12. 如何修改模型

**所有尺寸都在 `cad/lib/params.scad` 一个文件里。** 改完必做：

```bash
python tools/check_dims.py        # 设计规则（26 项）
python tools/lint_scad.py         # 语法与符号
python tools/verify_geometry.py   # 孔位与对位
python tools/export_stl.py        # 重新导出（需装 OpenSCAD）
```

**常见修改**：

| 想做什么 | 改哪个参数 |
|---|---|
| 键距 18 → 19 | `PITCH` |
| 键盘更薄 | 减小 `PCB_STANDOFF_H`（但要先确认电池装得下） |
| 换更大的电池 | `PCB_STANDOFF_H` 调大 + `BATT_*` |
| 换拨杆开关 | `SW_*` 系列 |
| 轴孔松紧 | `SWITCH_CUTOUT_TOL` |
| 键帽高度 | `CAP_H` |

> 这些脚本会**直接从 params.scad 读参数**，所以不存在「改了参数但校验还用旧值」的问题。

## 13. 本规格书的边界

**包含**：结构几何、内部布局、公差、打印参数、装配顺序、设计规则校验。

**不包含**：
- ❌ **电路设计（原理图 / PCB 布局）**——只定义「PCB 装在哪、多大、要开什么缺口」
- ❌ **ZMK 固件配置**
- ❌ **上位机软件**
- ❌ **打印服务报价**

**前置假设**：
- 0.4mm 喷嘴 FDM 打印机
- 材料 PLA / PETG
- 你按 §9 分步验证，而不是一次打全套

【尺寸】
